# 저장소의 모든 글은 한국어로 쓴다

이 저장소의 독자와 유지보수자는 한국어로 학습자료를 읽고 쓴다. 본문만 한국어이고 예제 주석이나 README가 영어이면, 독자는 같은 개념을 두 언어로 따라가야 하고 한 파일 안에서 언어가 섞인다. 그래서 본문, 지침, `_work/`, README, 코드 주석과 docstring, 도움말, 사람이 읽는 메시지, 커밋 메시지를 모두 한국어로 쓴다.

원문을 유지하는 것은 다음과 같다. 식별자와 코드, 명령과 옵션, 파일명과 경로, 패키지·도구·프로젝트의 고유 이름, 그리고 다른 프로그램이나 본문이 그대로 비교하는 출력 토큰(로그 키, 태스크 ID, CSV 열 이름 등)이다. 본문이 예상 출력으로 인용하는 문자열은 본문과 함께 바꿀 때만 바꾼다.

## 고려한 대안

- 코드와 주석은 영어, 산문은 한국어로 나누는 방식: 예제가 본문과 짝을 이루는 학습자료에서는 주석도 학습 설명의 일부라 언어가 갈리면 읽기 흐름이 끊긴다.

## 결과

문장은 명령형이나 중립적인 3인칭으로 쓰고, 한 문서 안에서는 문체를 하나로 통일한다. 독자나 요청자를 직접 부르는 말("여러분", "당신")은 쓰지 않는다.
