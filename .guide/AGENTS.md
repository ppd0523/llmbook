# 작성 가이드 작업 안내

저장소 공통 진입점은 [루트 AGENTS.md](../AGENTS.md)다. 이 파일은 기존 `.guide/AGENTS.md` 참조를 위한 연결점이며 `.guide/` 편집 시 아래 규칙을 적용한다.

- 문서별 역할과 템플릿 목록은 [README.md](README.md)를 따른다.
- 시작 판단·작업 순서·완료 기준은 [PROCESS.md](PROCESS.md), 파일 배치는 [OUTPUTS.md](OUTPUTS.md), 표현 규칙은 [MARKDOWN_STYLE.md](MARKDOWN_STYLE.md)에서 관리한다. 다른 문서에는 규칙을 복제하지 말고 링크한다.
- `01_scope.md`부터 `08_publish.md`까지는 재사용 템플릿이다. 실제 책의 내용과 작업 상태를 여기에 기록하지 않는다.
- 규칙 변경 시 관련 템플릿과 안내 문서의 모순도 확인한다. 지침 수정 자체에는 집필 단계를 적용하지 않는다.
