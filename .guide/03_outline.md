## 3. 학습 흐름

먼저 독자가 이 장에서 수행할 과제(연습문제·실습 과제)를 정한다. 개념 설명과 단계 안내는 그 과제에 필요한 만큼 붙인다. 과제는 쉬운 것에서 복잡한 것 순으로 놓고, 같은 원리를 겉모습이 다른 여러 사례로 연습하게 한다.

그다음 `01_scope.md`에서 정한 자료 유형의 골격을 고른다. 다른 순서가 낫다면 이유를 적는다.

| 자료 유형 | 챕터 골격 | 연습과 피드백 |
|---|---|---|
| 개념형 | 문제 제기 → 직관 예시 → 핵심 개념 → 형식화 → Worked Example → 직접 해보기 → 흔한 오류 → 요약 | 정답·해설이 있는 문제 |
| 실습형 | 완성 모습 → 준비 조건 → 단계별 실행과 기대 출력 → 실패 신호와 복구 → 변형 과제 → 요약 | 기대 출력이나 검증 명령으로 스스로 확인하는 과제 |
| 참조형 | 용어·옵션: 항목 정의 → 사용 위치 → 혼동하기 쉬운 항목 비교. 레시피: 목적 → 전제 조건 → 절차 → 결과 확인 | 연습은 생략할 수 있다. 레시피에는 결과 확인 방법을 둔다 |

실습형은 단계마다 독자가 성공 여부를 확인할 수 있는 기대 출력을 두고, 흔한 실패에는 알아보는 신호와 복구 방법을 함께 둔다.

### 절의 역할

챕터 안에서는 유형을 섞어도 되지만, 한 절은 다음 역할 중 하나만 맡는다. 개념을 설명하던 절에서 단계 절차로 넘어가면 독자가 지금 이해해야 하는지 따라 해야 하는지 알 수 없게 된다.

| 역할 | 내용 |
|---|---|
| 개념 | 원리, 모델, 판단 기준, 예시와 반례 |
| 절차 | 정해진 순서로 수행하는 단계와 명령 |
| 참조 | 찾아보기 위한 정의, 값, 옵션 목록 |
| 과제 | 독자가 직접 푸는 문제나 수행하는 실습 |

실습 절 안에서 배경 설명이 필요하면 한두 문장으로 줄이고, 자세한 설명은 개념 절이나 다른 장으로 링크한다.

## 10. 품질 점검

- [ ] 섹션 순서가 학습자의 선행지식 흐름과 맞는다.
- [ ] 새 용어가 정의 없이 먼저 등장하지 않는다.
- [ ] 새 용어의 첫 등장 위치와 설명 방식이 정해져 있다.
- [ ] 용어 설명에 아직 정의하지 않은 다른 새 용어를 사용하지 않는다.
- [ ] 각 핵심 개념에 예제 또는 확인 질문이 대응된다.
- [ ] 최종 연습문제가 학습 목표와 대응된다.
- [ ] 학습 흐름이 자료 유형에 맞다.
- [ ] 독자가 수행할 과제가 먼저 정해져 있고, 개념·절차 절이 그 과제에 연결된다.
- [ ] 각 절이 개념·절차·참조·과제 중 한 역할만 맡는다.
- [ ] 모든 연습문제·과제에 피드백 방식이 정해져 있다.
