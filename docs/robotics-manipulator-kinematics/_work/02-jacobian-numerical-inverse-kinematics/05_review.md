# 4단계 기술 검증

## 검증 대상

- 정의: 변화량, 2-노름, 미분, 편미분, 자코비안, 랭크, 특이 자세, 의사역행렬, DLS, 외적, 영공간
- 수식: 2R 자코비안, 행렬식, 유한차분, 역행렬 업데이트, DLS, 3D 기하 자코비안 열, 방위 오차, 영공간 해
- 알고리즘: FK→오차→자코비안→업데이트→종료의 반복 수치 IK
- 예제: 정상 자세의 역행렬 업데이트, 완전 신장 자세의 DLS 업데이트
- 실습: DLS·Jacobian transpose, 정상·특이 근처·완전 신장·도달 불가 프리셋
- 범위: 제어·동역학·힘·토크를 제외한 기구학 계산

## 실습 검증

- JavaScript 구문 검사 통과
- 정적 HTML ID 중복 없음
- 프리셋 4개 존재
- 정상 자세: DLS 3회에 오차 0.005 미만
- 정상 자세 + 자코비안 전치: $\eta=0.8$이면 두 자세 사이를 오가며 오차 0.159·0.180이 반복되어 300회에서 최대 반복으로 끝난다. $\eta\le0.6$이면 수렴하고 $\eta=0.3$에서 18회다.
- 특이 근처: DLS 6회에 오차 0.005 미만. 첫 업데이트는 $\lambda=0.01$이면 제한 전 약 500°라 최대 스텝 30°에서 $(-12.95°,27.06°)$로 잘리고, $\lambda=0.3$이면 $(6.72°,5.49°)$, 크기 8.68°다. 프리셋의 최대 스텝 10°에서는 두 경우 모두 제한에 걸린다.
- 완전 신장: 첫 업데이트 $(0.0399202,0.0199601)$ rad가 본문 DLS 한 단계와 같고, 반올림한 관절각 $(2.3°,1.1°)$의 끝점은 $(1.9974,0.0994)$다. DLS 9회에 오차 0.005 미만
- 도달 불가: 두 자세 사이를 오가며 $\|\Delta\mathbf q\|$가 최대 스텝 10°에 걸린 채 오차 0.3447·0.3457이 반복되고, 300회에서 최대 반복으로 끝난다. `정체`는 나오지 않는다. 목표까지 거리는 2.3436이다.
- 확인 방법: 위 반복 횟수와 업데이트는 실습 HTML의 풀이 코드(프리셋 값, FK, 자코비안, DLS·전치 업데이트, 스텝 제한, 종료 판정)를 Python 스크립트로 옮겨 실행해 확인했다. 관절각 입력은 0.1° 단위 `range` 입력이라 매 반복의 각도가 0.1°로 반올림되므로 이를 반영했다. 반올림을 빼고 계산하면 특이 근처는 7회, 완전 신장은 8회다. 브라우저에서 직접 실행해 다시 세지는 않았다.
- 슬라이더·알고리즘을 바꾸거나 캔버스를 누르면 그 순간의 자세가 새 시작점이 되고, 프리셋은 알고리즘과 설정값까지 되돌린다. 본문 15절의 실험 순서는 이 동작에 맞춘다.
- 캔버스 목표 선택, 한 단계·30단계·초기화 동작의 이벤트 연결 확인
- 브라우저에서 정상 프리셋은 3회 수렴하고 초기화 뒤 $(0°,90°)$·반복 0으로 복원됨
- $q_1=25°$와 자코비안 전치 방법을 직접 선택한 뒤 한 단계 실행해도 초기화가 그 시작값·방법을 복원함
- 360px 폭에서 가로 넘침 없이 단일 열로 재배치되고 캔버스와 초기화 버튼이 표시됨
- 브라우저 콘솔 오류 없음
- 동적 상태 설명에 `aria-live` 적용

## 남은 위험

- 외적 기반 방위 오차는 큰 회전 전체를 표현하는 공식이 아니다. 적용 범위는 본문에 명시되어 있다.
- DLS의 수렴은 초기값, 스텝, 감쇠, 목표 도달성과 관절 제한에 의존한다. 전역 수렴을 보장하지 않는다.
- 혼합 R/P 관절과 6D 과제의 가중치 선택에는 문제별 스케일이 필요하다.
- 실습은 2R 위치 IK에 집중하며 6R 방위 IK 구현을 대체하지 않는다.
- 브라우저 화면은 2D 투영이므로 정확한 판단은 수치와 행렬을 함께 사용한다.

## 검증 결론

2R 유도, 특이점 조건, DLS 공식, 두 풀이 예제, 3D 기하 자코비안 열과 국소 방위 오차가 출처 및 수치 검사와 일치한다. 본문은 수치 IK를 제어와 구분하고, 좌표계·단위·국소 근사·종료 조건의 적용 범위를 밝힌다.
