# 4단계 초고

## 중심 흐름

3단계의 FK $\mathbf x=f(\mathbf q)$는 관절값에서 말단 자세를 계산한다. 일반적인 6R 팔이나 휴머노이드는 이 식을 한 번 뒤집기 어렵다. 현재 자세 주변에서만 FK를 직선처럼 근사하면 $\Delta\mathbf x\approx J\Delta\mathbf q$를 얻고, 이 관계를 거꾸로 풀어 작은 관절 업데이트를 반복할 수 있다.

## 설명 뼈대

1. 1R 끝점에서 작은 각도 변화가 접선 방향 이동을 만든다는 그림으로 변화율을 시작한다.
2. 편미분을 `다른 관절은 고정하고 한 관절만 바꾼 기울기`로 정의한다.
3. 1단계의 2R FK를 편미분해 $2\times2$ 위치 자코비안을 만든다.
4. 각 열을 한 관절의 단위 변화가 만드는 말단 이동으로 해석하고 유한차분으로 확인한다.
5. 두 열이 나란해질 때 한 방향을 만들 수 없다는 사실에서 특이 자세와 랭크를 도입한다.
6. 역행렬은 정사각·비특이 조건에서만 가능하므로 의사역행렬과 감쇠 최소제곱이 필요한 이유를 설명한다.
7. 정상 자세의 한 번 업데이트와 완전 신장 자세의 DLS 업데이트를 계산한다.
8. FK→오차→자코비안→업데이트→종료의 수치 IK 반복 절차를 제시한다.
9. 외적을 소개하고 회전·직동관절의 3D 기하 자코비안 열로 확장한다.
10. 위치·방위 오차의 좌표계와 단위를 맞춘 뒤 6R 자세 IK로 연결한다.
11. 영공간과 다중 과제를 소개해 5단계 전신 IK를 준비한다.

## 예제 후보

- $l_1=l_2=1$, $\mathbf q=(0°,90°)$, 현재 위치 $(1,1)$, 목표 $(0.9,1.1)$에서 $\Delta\mathbf q=(0.1,0)$ rad를 얻는다.
- $l_1=l_2=1$, $\mathbf q=(0°,0°)$에서 위쪽 오차 $(0,0.1)$에 DLS를 적용해 유한한 업데이트를 얻는다.
- 유한차분 $\varepsilon=10^{-4}$ rad로 해석 자코비안 열과의 차이를 검사한다.

## 실습 초고

- 입력: $q_1,q_2$, 목표 $(x_d,y_d)$, 방법, 스텝 크기 $\eta$, 감쇠 $\lambda$.
- 출력: 현재 팔과 목표, 오차 벡터, 자코비안 열, 반복 경로, $\det J$, 업데이트, 종료 이유.
- 동작: 한 단계, 30단계, 초기화, 정상·특이 근처·도달 불가 프리셋.
- 주의: 브라우저 실습은 2R 위치 IK이며 6D 방위 IK를 직접 구현하지 않는다.

## 범위 경계

- 반복 업데이트는 기구학 계산이며 모터 제어나 PID·PD가 아니다.
- 자코비안 전치의 힘·토크 관계는 다루지 않는다.
- SVD 계산, 조작성 타원체, 충돌 회피와 우선순위 전신 IK는 다음 자료로 넘긴다.
