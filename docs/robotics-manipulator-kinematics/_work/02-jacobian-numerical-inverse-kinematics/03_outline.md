# 4단계 개요

1. FK를 반복해서 IK로 바꾸는 문제
   - 현재 자세에서 목표까지의 오차
   - 한 번에 정확히 푸는 식과 국소 근사의 차이
2. 작은 변화를 읽는 수학
   - 변화량, 벡터 크기, 라디안
   - 기울기, 편미분, 점 표기
3. 자코비안의 정의
   - $\Delta\mathbf x\approx J\Delta\mathbf q$
   - 속도 관계와 각 열의 의미
4. 2R 위치 자코비안 유도
   - 1단계 FK를 $q_1,q_2$로 편미분
   - 행·열과 단위 읽기
5. 자코비안 열벡터와 유한차분
   - 한 관절만 조금 움직이기
   - 해석식과 수치 근사 비교
6. 특이 자세
   - 독립 방향, 랭크의 직관
   - $\det J=l_1l_2\sin q_2$
7. 국소 관계를 거꾸로 풀기
   - 역행렬의 적용 조건
   - Jacobian transpose와 Moore–Penrose 의사역행렬
8. 감쇠 최소제곱
   - 잔차와 관절 변화 크기의 절충
   - $J^T(JJ^T+\lambda^2I)^{-1}$
9. 수치 IK 반복 알고리즘
   - FK, 오차, 자코비안, 업데이트, 종료
   - 스텝 제한, 관절 제한, 정체와 도달 불가
10. Worked Example 1
    - 정상 자세에서 2R 한 번 업데이트
    - 실제 FK와 선형 예측의 차이
11. Worked Example 2
    - 완전 신장 자세에서 DLS 업데이트
    - 감쇠값의 효과
12. 3D 기하 자코비안
    - 외적의 정의
    - 회전·직동관절 열 공식
13. 6차원 자세 오차
    - 선속도·각속도 순서
    - 회전행렬 열을 이용한 국소 방위 오차
    - 좌표계, 단위, 가중치
14. 휴머노이드 전신 IK로 연결
    - 여유 자유도와 영공간
    - 여러 발·골반 과제와 우선순위의 필요성
15. 인터랙티브 실습
16. 흔한 실수
17. 연습문제와 정답
18. 요약, 다음 단계, 추가 읽을거리, 참고문헌

## 개념 의존성

```text
3단계 FK
  -> 작은 변화와 편미분
  -> 2R 자코비안
  -> 열벡터와 국소 선형 근사
  -> 특이 자세
  -> 의사역행렬과 DLS
  -> 반복 수치 IK
  -> 외적과 3D 기하 자코비안
  -> 6D 자세 오차
  -> 여유 자유도와 전신 IK 준비
```

| 휴머노이드 연결 | 영공간과 다중 과제 | 10 |

## 시각화 계획

- 2R 팔, 목표점, 현재 오차와 반복 경로를 한 캔버스에 표시한다.
- 두 자코비안 열을 서로 다른 색과 `J₁`, `J₂` 라벨로 표시한다.
- 정상, 특이 근처, 도달 불가 프리셋을 제공한다.
- Jacobian transpose와 DLS를 같은 초기조건에서 비교한다.
- 한 단계 실행, 여러 단계 실행, 초기화만 제공해 상호작용을 단순하게 유지한다.
- 오차 크기, $\det J$, 관절 업데이트와 종료 이유를 수치로 표시한다.
