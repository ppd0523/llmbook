# 4단계 퇴고 기록

## 퇴고 목표

- 미분을 모르는 독자가 FK에서 자코비안으로 자연스럽게 이동하게 한다.
- 기호 정의보다 행렬 공식이 먼저 나오지 않게 한다.
- 자코비안을 편미분 표가 아니라 관절별 말단 운동의 모음으로 읽게 한다.
- 특이점의 기하 직관을 먼저 제시한 뒤 역행렬의 한계를 설명한다.
- 정상 자세와 특이 자세의 수치 예를 나란히 제공한다.
- 2R 위치 IK의 단순한 예에서 6R 자세 IK와 휴머노이드 전신 IK의 전제로 확장한다.
- 수치 IK, 제어, 동역학의 범위를 분리한다.

## 학습성 점검

- [x] 모든 새 수학 용어를 첫 사용 전에 정의한다.
- [x] 단순한 위치 오차와 회전행렬 방위 오차를 분리한다.
- [x] 1R 접선 직관 뒤에 2R 편미분을 배치한다.
- [x] $q_1+q_2$ 미분 전에 연쇄법칙을 짧게 설명한다.
- [x] $\Delta\mathbf x\approx J\Delta\mathbf q$의 근사 조건을 반복해 상기시킨다.
- [x] 자코비안의 행·열·단위를 함께 읽는다.
- [x] 해석 자코비안과 유한차분을 서로 검산한다.
- [x] 특이점의 행렬 조건과 기구 그림의 의미를 연결한다.
- [x] DLS가 도달 불가를 해결하지 못한다는 반례를 포함한다.
- [x] 3D 식의 벡터가 같은 좌표계에 있어야 함을 명시한다.
- [x] 위치와 방위의 단위 차이를 가중치로 다룬다.
- [x] 과제·도구점·표현 좌표계에 따라 자코비안이 달라짐을 예로 확인한다.
- [x] 다중 과제 가중치와 엄격한 우선순위를 구분한다.
- [x] 연습문제는 본문 수식과 실습만으로 풀 수 있다.

## 최종화 전 확인

- [x] 기술 검증의 수정 사항을 반영했다.
- [x] 학습 목표와 본문·연습문제가 대응한다.
- [x] PID·PD, 동역학, 힘·토크 계산을 포함하지 않았다.
- [x] 새 용어가 정의 없이 먼저 사용되지 않는다.
- [x] 내부 메모와 미검증 표지는 최종 원고에 남기지 않는다.
- [x] 공개 강의·교과서·논문 출처와 본문 주장이 대응한다.
