# 4단계 독자 검증과 퇴고 기록

## 1. 독자 검증

- 검토자: 별도 서브에이전트 1개
- 검토자에게 준 정보: `01_scope.md`의 대상 독자(1~3단계 학습, 미분·편미분·외적·랭크·의사역행렬은 모름), 3단계 교육용 6R의 식과 풀이 예제 1의 결과, 정답 블록을 지운 챕터 본문 사본, 본문이 쓰라고 지시하는 `numerical-ik-lab.html`. 정답은 17절 문제의 답을 모두 정한 뒤에만 열게 했다. `_work/`는 주지 않았다.
- 방법: 본문만 읽고 문제 13개를 푼 뒤 정답과 대조했다. 실습은 브라우저 대신 소스를 읽고, 계산 코드와 종료 판정, 0.1° 슬라이더 반올림, 입력 변경 시 시작점 재설정을 Node.js로 옮겨 15절 실습 단계 1~7의 기대값과 비교했다.
- 결과: 13문제 모두 정답과 일치했다. 정답 계산 오류는 없었다.
- 남은 문제: 없다. 검토자가 지적한 항목(실습 4단계에서 최대 스텝 10°일 때 $\lambda=0.3$은 제한에 걸리지 않는다는 점, 화면에 $\|\Delta\mathbf q\|$가 표시되지 않는 점, 0.1° 반올림으로 달라지는 끝점, $\det J$ 전개 과정, 문제 10의 관절 1 축 정보, 실습 6단계의 누름 횟수)은 모두 현재 본문에 반영되어 있다. 반영한 뒤의 본문으로 독자 검증을 다시 하지는 않았다.

## 2. 퇴고 목표

- 구조: 미분을 모르는 독자가 FK에서 자코비안, 특이점, DLS, 반복 IK, 3D 기하 자코비안으로 이동하게 한다.
- 학습성: 자코비안을 편미분 표가 아니라 관절별 말단 운동의 모음으로 읽게 하고, $\det J=l_1l_2\sin q_2$를 전개해 보인다.
- 연습: 풀이 예제를 옮겨 적는 것만으로 풀리는 문제를 두지 않는다. 3·4·7번은 풀이 예제와 다른 자세 $(90°,-90°)$에서 자코비안, 열 조합, 역행렬 업데이트와 FK 잔차를 계산하게 하고, 8번은 $\lambda$ 두 값을 비교하게 하며, 10번은 3단계 교육용 6R의 관절축으로 기하 자코비안 열을 만들게 한다.
- 실습: 프리셋·슬라이더 동작에 맞춘 실험 순서와, 실제 표시되는 수치(반복 횟수, 진동하는 오차, 제한된 $\Delta\mathbf q$)를 본문에 적는다.
