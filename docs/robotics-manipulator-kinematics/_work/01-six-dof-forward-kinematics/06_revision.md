# 3단계 독자 검증과 퇴고 기록

## 1. 독자 검증

- 검토자: 별도 서브에이전트 1개
- 검토자에게 준 정보: `01_scope.md`의 대상 독자(고등학교 행렬·삼각함수, 1·2단계 학습, DH·직렬 기구는 모름), 정답 블록을 지운 챕터 본문 사본, 본문이 쓰라고 지시하는 `forward-kinematics-lab.html`. 정답은 15절 문제의 답을 모두 정한 뒤에만 열게 했다. `_work/`는 주지 않았다.
- 방법: 본문만 읽고 문제 10개를 푼 뒤 정답과 대조했다. 실습은 브라우저 대신 소스를 읽고, `chain()` 계산을 Node.js로 옮겨 13절 실습 단계의 기대값과 비교했다.
- 결과: 10문제 모두 정답과 일치했다. 정답 계산 오류는 없었다.
- 남은 문제: 없다. 검토자가 지적한 막힌 지점(6R 곱과 인접 변환의 대응, 프레임 3~6 원점이 손목 중심에 겹치는 이유, $R_y$ 양의 회전이 링크를 내리는 이유, 회전행렬 둘째·셋째 열의 뜻, 교차 축의 $x_i$ 방향, 프리셋이 $L_t$를 되돌려 실습 5단계가 재현되지 않던 문제, 정답 3·7의 표현)은 모두 현재 본문에 반영되어 있다. 반영한 뒤의 본문으로 독자 검증을 다시 하지는 않았다.

## 2. 퇴고 목표

- 구조: 관절 하나, 변환 체인, 교육용 6R, DH 순으로 개념 의존성을 맞춘다.
- 학습성: 긴 6R 곱을 4절의 인접 변환 표로 나누어 중간 좌표계를 예측할 수 있게 한다.
- 연습: 풀이 예제를 옮겨 적는 것만으로 풀리는 문제를 두지 않는다. 7번은 $\alpha=90°$인 DH 표와 직접 나열한 체인을 비교해 관절축 방향과 변수 부호를 판단하게 하고, 9번은 행렬식이 $-1$인 반사 행렬을 함께 판정하게 한다.
- 실습: 본문의 실습 지시가 실제 프리셋 동작(링크 길이까지 되돌림)과 맞게 한다.
