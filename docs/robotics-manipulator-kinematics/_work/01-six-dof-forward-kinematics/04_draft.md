# 3단계 초안 메모

## 서술 흐름

2단계 마지막 식 ${}^0T_6={}^{0}T_1\cdots{}^5T_6$에서 바로 시작한다. 먼저 여섯 관절을 가진 교육용 팔을 기본 변환의 연쇄로 적어 FK의 목적과 출력을 확인한다. 그 뒤 같은 작업을 규칙적인 표로 기록하는 표준 DH를 소개한다.

DH 좌표계 배치는 처음 배우는 사람에게 가장 어려운 구간이다. 따라서 네 매개변수를 모두 외우게 하기 전에 `z축 회전 → z축 이동 → x축 이동 → x축 회전`이라는 한 문장을 고정하고, 1단계 2R 예제로 결과를 검산한다.

## 초안에서 해결할 혼동

- `6자유도`와 `6R`을 같은 뜻으로 쓰지 않는다. 6R은 회전관절 여섯 개라는 기구 형태다.
- 관절 수가 여섯이면 모든 자세에 항상 도달한다고 말하지 않는다.
- 링크 번호와 관절 번호, ${}^{i-1}T_i$의 변환 방향을 분리해서 설명한다.
- 말단 프레임, 플랜지, 실제 작업점 TCP를 같은 점으로 취급하지 않는다.
- 표준 DH와 수정 DH의 이름·곱 순서를 반드시 함께 기록한다.
- DH 표의 $a_i$와 1단계 링크 길이 기호 $l_i$는 특정 예에서만 같다는 점을 밝힌다.
- 손목 중심이 고정되어도 도구 오프셋 때문에 TCP 위치는 바뀔 수 있음을 실습으로 확인한다.

## 핵심 Worked Example

- 교육용 6R 팔: $h=2$, $L_2=3$, $L_3=2$, $L_t=1$, $\mathbf q=[90°,0°,90°,0°,0°,0°]^T$
- 기대 손목 중심: $(0,3,0)$
- 기대 TCP: $(0,3,-1)$
- 기대 방위: $R_z(90°)R_y(90°)$
- DH 예제: 평면 2R 표에서 1단계 FK 식 복원

## 실습 초안

- 입력: $q_1$~$q_6$, 링크 길이, 누적 변환 단계
- 출력: 베이스·어깨·팔꿈치·손목·TCP, TCP 좌표축, 선택한 ${}^0T_i$, 최종 ${}^0T_6$, 회전행렬 검사
- 프리셋: 홈, Worked Example, 팔 자세, 같은 팔 자세에서 손목만 회전
- 관찰: $q_1$~$q_3$과 $q_4$~$q_6$의 영향, 손목 중심과 TCP의 차이
