# 3단계 범위 정의

## 핵심 질문

여섯 관절이 직렬로 연결된 로봇 팔에서 각 관절값으로부터 도구의 위치와 방위를 나타내는 순기구학을 어떻게 구성하고 검산하는가?

## 대상 독자와 선수 지식

- 고등학교 수준의 행렬 곱셈과 삼각함수를 안다.
- 1단계 `평면 회전과 2관절 IK`, 2단계 `3D 회전과 강체변환`을 학습했다.
- 직렬 기구, 회전관절·직동관절, 말단장치, DH 매개변수는 모를 수 있다고 가정한다.
- 코드 구현 경험은 요구하지 않는다. 브라우저 실습으로 행렬 계산을 관찰한다.

## 학습 목표

학습자는 이 장을 마친 뒤 다음을 할 수 있어야 한다.

1. 직렬 열린 사슬, 링크, 회전관절, 직동관절, 말단장치와 도구 중심점을 구별한다.
2. 관절공간의 입력 $\mathbf q$와 말단 자세 공간의 출력 ${}^0T_6(\mathbf q)$를 구별한다.
3. 기본 회전·이동을 관절 순서대로 곱해 6R 팔의 순기구학 체인을 구성한다.
4. 표준 Denavit–Hartenberg(DH) 네 매개변수와 한 행의 변환행렬을 읽는다.
5. 2R 예제의 DH 표에서 순기구학을 만들고 1단계 식과 일치함을 확인한다.
6. 베이스·플랜지·도구 변환을 포함해 실제 목표 자세를 표현한다.
7. 홈 자세, 중간 좌표계, 회전행렬 조건으로 순기구학 결과를 검산한다.
8. 6개 관절이라는 사실만으로 모든 자세가 항상 가능하다고 결론 내릴 수 없는 이유를 설명한다.

## 포함 범위

- 열린 사슬과 닫힌 사슬의 구분
- 회전관절(R)과 직동관절(P)의 기구학적 변환
- 링크 좌표계, 베이스 좌표계, 플랜지, 말단장치, 도구 중심점(TCP)
- 관절벡터와 순기구학 함수
- 기본 변환을 직접 잇는 변환 체인
- 직관적인 6R 팔의 전체 FK 예제
- 표준 DH 규약의 축 배치, 네 매개변수, 한 행 변환식
- 2R DH Worked Example과 DH 표 검산 절차
- 표준 DH와 수정 DH를 섞지 말아야 한다는 경고
- 베이스·도구 고정 변환
- 구면 손목과 위치·방위 분리의 입문적 직관
- 독립 실행형 인터랙티브 HTML 실습과 연습문제

## 제외 범위

- PID·PD 제어와 모든 제어기 설계
- 힘, 토크, 질량, 관성, 중력 등 동역학
- 모터, 감속기, 센서, 보정 알고리즘
- Jacobian 유도, 속도 기구학, 특이값, 수치 IK
- 6자유도 해석적 IK의 전체 해법
- twist, screw axis, 행렬지수와 POE 공식의 계산
- 충돌 회피, 관절 제한을 포함한 경로·궤적 계획
- URDF 문법과 특정 로봇 제조사 모델

## 성공 기준

- 학습자가 주어진 변환 순서와 관절값으로 ${}^0T_6$을 계산하고 위치와 방위를 읽는다.
- 학습자가 표준 DH 한 행을 네 기본 변환과 $4\times4$ 행렬로 바꾼다.
- 학습자가 2R DH 표로 1단계 FK 식을 다시 얻는다.
- 학습자가 실습에서 $q_1$부터 $q_6$까지 바꾸고 누적 변환과 TCP 자세가 갱신되는 것을 확인한다.
- 학습자가 손목 관절만 바꿀 때 손목 중심과 TCP가 어떻게 다르게 움직이는지 설명한다.
