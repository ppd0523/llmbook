# 3단계 개요

1. 관절 여섯 개를 하나의 자세로 바꾸는 문제
   - 관절공간과 말단 자세 공간, 작업공간과의 용어 구분
   - FK는 함수, IK는 역문제
2. 직렬 매니퓰레이터의 구성요소
   - 열린 사슬, 링크, R/P 관절
   - 베이스, 링크 좌표계, 플랜지, 말단장치, TCP
3. 관절 하나의 변환
   - $\operatorname{Rot}_z(q)$와 $\operatorname{Trans}_z(q)$
   - 고정 링크 변환과 관절변수 분리
4. 변환 체인으로 만드는 FK
   - ${}^0T_6={}^{0}T_1\cdots{}^5T_6$
   - 알고리즘과 중간 좌표계
5. 교육용 6R 팔
   - base yaw, shoulder/elbow pitch, 3축 손목
   - Worked Example: 정수 좌표가 나오는 자세
6. DH 표가 필요한 이유
   - 좌표계 선택을 일정하게 기록
   - 표준 DH와 수정 DH의 구분
7. 표준 DH 네 매개변수
   - $\theta,d,a,\alpha$의 순서와 단위
   - 한 행의 $4\times4$ 행렬
8. DH 좌표계와 표 작성 절차
   - z축은 관절축, x축은 공통수선
   - 애매한 경우 규약을 끝까지 유지
9. Worked Example: 2R 팔의 DH FK
   - 1단계 식과 일치 확인
10. 베이스와 도구 변환
    - ${}^WT_{TCP}={}^{W}T_0{}^0T_6{}^6T_{TCP}$
11. FK 검산법
    - 홈 자세, 중간 원점, $R^TR=I$, 단위와 변환 방향
12. 6R에서 IK로 넘어가기
    - 구면 손목과 손목 중심
    - 여섯 관절이 만능을 보장하지 않음
13. 인터랙티브 실습
14. 흔한 실수
15. 연습문제와 정답
16. 요약, 추가 읽을거리, 참고문헌

## 개념 의존성

```text
2단계 강체변환
  -> R/P 관절의 가변 변환
  -> 직렬 변환 체인
  -> 6R FK
  -> 표준 DH 한 행
  -> DH 표와 누적 곱
  -> 베이스·도구 변환
  -> IK와 Jacobian의 입력 준비
```
