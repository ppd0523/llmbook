# 범위·호환성·제어 모델

## EDSDK가 제어하는 것

EDSDK는 컴퓨터와 카메라 사이의 제어·전송 계층이다. 카메라를 단순 저장 장치로 여는
도구가 아니라, 카메라의 현재 상태를 읽고 속성을 바꾸며 촬영 요청과 비동기 이벤트를
교환하는 장치 제어 SDK다. 캐논은 이를 USB 유선 연결에서 고속 전송을 제공하는 SDK로
설명하며, 원격 촬영, 이미지 전송, 카메라 설정, 라이브 뷰 모니터를 주요 범주로 든다.
[Camera API Package 개요](https://asia.canon/en/campaign/developerresources/camera/cap/cap)

이 매뉴얼의 기준은 `EDSDK.dll`을 포함한 Windows용 패키지다. DLL을 호출하는 언어와
상관없이 아래의 **객체·속성·명령·이벤트** 모델은 같다.

| 요소 | 뜻 | 운용에서의 역할 |
|---|---|---|
| SDK 수명 | 라이브러리 사용을 시작하고 끝내는 범위 | 한 프로세스에서 한 번 초기화하고, 모든 세션·객체를 정리한 뒤 종료한다. |
| 카메라 목록 | 연결된 원격 카메라의 목록 | 대상 카메라를 찾는다. 다중 연결이면 모델명·포트 등으로 선택 정책을 정한다. |
| 카메라 세션 | 특정 카메라와 맺은 논리 연결 | 속성 변경, 촬영, 라이브 뷰, 이벤트 등록은 이 세션 안에서 한다. |
| 속성(property) | ISO·저장 위치·EVF 출력 대상 같은 값 | 먼저 읽고, 자료형과 허용 값 목록을 확인한 뒤 바꾼다. |
| 명령(command) | 셔터 누름·AF 실행·렌즈 구동 같은 동작 요청 | 요청을 보낸 뒤 이벤트나 속성 변화를 기다린다. |
| 이벤트(event) | 파일 생성, 속성 변경, 연결 해제 같은 비동기 통지 | 폴링만으로 놓치기 쉬운 결과를 처리한다. |
| 참조 객체(reference) | 카메라, 파일, 스트림, EVF 이미지 등 SDK가 관리하는 객체 | 더 이상 쓰지 않으면 해제한다. 이벤트에서 받은 객체도 예외가 아니다. |

## 기준 기종과 이름

| 이 문서의 이름 | 지역별 같은 기종 | EDSDK 호환성 근거 |
|---|---|---|
| EOS 200D | EOS Kiss X9, EOS Rebel SL2 | 캐논 호환성 목록에 명시 |
| EOS 200D Mark II | EOS Kiss X10, EOS Rebel SL3, EOS 250D | 캐논 호환성 목록 및 EDSDK 릴리스 노트에 명시 |
| EOS 850D | EOS Kiss X10i, EOS Rebel T8i | 캐논 호환성 목록 및 EDSDK 릴리스 노트에 명시 |

호환 목록은 **SDK가 카메라에 연결될 수 있음**을 뜻할 뿐, 특정 렌즈·촬영 모드·펌웨어에서
모든 세부 기능이 가능하다는 보증은 아니다. 특히 AF 방법, 초점 위치 지정, 원격 초점
구동, 동영상, 라이브 뷰 정보 오버레이는 카메라와 렌즈의 실제 상태를 확인해야 한다.

## 제어 상태 흐름

안정적인 제어 프로그램은 다음 순서를 지킨다. 중간 단계를 건너뛰면 “명령은 성공했는데
사진이나 프레임이 없다”는 문제가 생기기 쉽다.

```text
SDK 초기화
  → 카메라 목록 취득·대상 확인
  → 이벤트 수신기 등록
  → 세션 열기
  → 현재 설정·허용값 확인
  → 작업 실행(촬영 / 라이브 뷰 / 초점 / 전송)
  → 작업 결과 이벤트 처리·객체 해제
  → 라이브 뷰 중지·필요시 설정 복원
  → 세션 닫기·객체 해제
  → SDK 종료
```

이 순서에서 이벤트 등록을 세션 개방 전에 두는 이유는 세션을 열거나 설정을 바꾸는 동안
발생한 상태 변화를 놓치지 않기 위해서다. 구버전 캐논 API 참조서도 SDK 초기화, 카메라
목록 취득, 객체·속성·상태 이벤트 등록, 세션 개방의 순서를 예시한다.
[EDSDK API Programming Reference, 2016](https://downloads.triprism.com/public/%5B%20Steve%20%5D/forTyler/canon%203.4sdk/EDSDK_API%203.4.pdf)

## 작업 시작 전 점검

1. 카메라 배터리를 충분히 충전하거나 적절한 외부 전원을 쓴다. 장시간 라이브 뷰는 배터리와
   발열 부담이 크다.
2. 데이터 전송이 가능한 USB 케이블로 컴퓨터에 직접 연결한다. 허브·연장 케이블은 먼저
   제외하고 확인한다.
3. EOS Utility, Digital Photo Professional, 브라우저 연결 앱 등 카메라 세션을 점유할 수 있는
   프로그램을 닫는다. 한 카메라를 동시에 제어하려고 하지 않는다.
4. 카메라를 켜고 자동 전원 꺼짐 시간을 작업 시간보다 길게 잡는다. 장시간 작업은
   `ExtendShutDownTimer` 계열의 유지 요청도 주기적으로 고려한다.
5. 정지 사진을 카드에 저장하거나 동영상을 녹화할 계획이면 정상 동작하는 메모리 카드를
   넣는다. 동영상은 이 기준 기종에서 카드 기록을 전제로 설계하는 편이 안전하다.
6. AF를 쓸 때는 AF 가능한 렌즈를 장착하고 렌즈의 포커스 모드 스위치를 `AF`에 둔다.
   원격 초점 구동을 시험할 때도 렌즈·바디 조합의 지원 여부를 먼저 확인한다.

## 기능을 확인하는 원칙

각 기능을 “이 기종이 지원한다/안 한다”로 하드코딩하지 말고, 연결된 세션에서 다음
순서로 판정한다.

1. 관련 속성의 자료형과 현재 값을 읽는다.
2. 그 속성에 설정 가능한 값 목록을 조회한다.
3. 필요한 명령을 한 번 시험하고 반환 오류·후속 이벤트·속성 변화를 함께 확인한다.
4. 지원하지 않음 또는 현재 상태에서 불가한 오류라면 사용자에게 원인과 대안을 보여 준다.

예를 들어 `kEdsPropID_AFMode`는 카메라의 촬영 AF 설정이고,
`kEdsPropID_Evf_AFMode`는 라이브 뷰 AF 방식이다. 이름이 비슷해도 같은 값을 바꾸거나
같은 효과를 보장하지 않는다. 공개 헤더와 캐논의 기능 개요는 EVF AF 모드, AF 위치, 초점
정보가 별도 기능 단위임을 보여 준다.
[공개 EDSDK 헤더 사례](https://github.com/andrewrk/pyedsdk/blob/master/edsdk/EDSDKTypes.h)
