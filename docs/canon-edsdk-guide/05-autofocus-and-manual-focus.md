# 자동초점과 원격 초점 구동

## 세 가지를 구분한다

초점 제어에서 “AF 모드”, “AF 실행”, “원격 초점 구동”은 서로 다른 일이다.

| 기능 | EDSDK의 대표 요소 | 뜻 |
|---|---|---|
| 촬영 AF 설정 | `kEdsPropID_AFMode` | 카메라의 촬영용 AF 관련 설정을 읽거나 변경한다. |
| 라이브 뷰 AF 방식 | `kEdsPropID_Evf_AFMode` | 라이브 뷰에서 쓰는 AF 방식·표시 상태를 다룬다. |
| 일회 AF 실행 | `kEdsCameraCommand_DoEvfAf` | 라이브 뷰 중 카메라에 자동초점 동작을 요청한다. |
| 셔터 반누름 AF | `PressShutterButton`의 `Halfway` | 카메라·렌즈 설정에 따르는 측광/AF 후 촬영 흐름이다. |
| 렌즈 초점 구동 | `kEdsCameraCommand_DriveLensEvf` | 라이브 뷰 중 렌즈를 가까운 쪽·먼 쪽으로 단계 이동하도록 요청한다. |

공개 EDSDK 헤더는 위 명령과 속성을 별도로 정의하고, 캐논 API 참조서는 `DoEvfAf`가
라이브 뷰 중의 AF 제어이며 `DriveLensEvf`가 라이브 뷰에서 렌즈를 구동하는 명령이라고
설명한다.
[공개 EDSDK 헤더 사례](https://github.com/andrewrk/pyedsdk/blob/master/edsdk/EDSDKTypes.h),
[EDSDK API Programming Reference](https://downloads.triprism.com/public/%5B%20Steve%20%5D/forTyler/canon%203.4sdk/EDSDK_API%203.4.pdf)

## 일회 AF: 제품 촬영에 적합한 기본 경로

고정된 피사체를 촬영하는 경우는 다음 순서가 가장 예측 가능하다.

1. 렌즈의 포커스 모드를 AF로 두고, 카메라가 라이브 뷰를 지원·실행 중인지 확인한다.
2. 라이브 뷰 프레임과 EVF AF 관련 상태를 표시한다.
3. `DoEvfAf`로 AF 시작을 요청한다.
4. AF 결과·초점 프레임·렌즈 상태 변화 또는 충분한 완료 대기 조건을 확인한다.
5. 성공했을 때만 셔터 완전 누름을 허용한다. 실패·미확정이면 재시도 또는 원격 초점 구동 화면으로
   전환한다.

일회 AF는 “계속 추적하는 AF”가 아니다. 캐논의 라이브 뷰 안내도 AF 방식과 AF 영역에서
가능한 기능은 연결 카메라의 사용 설명서를 확인해야 하며, 렌즈 스위치를 AF에 두라고
안내한다. 움직이는 피사체의 지속 추적을 EDSDK 일회 AF 명령만으로 보장하지 않는다.
[EOS Utility Remote Live View 안내](https://cam.start.canon/tc/S003/manual/html/UG-03_RemoteCamera_0070.html)

## 원격 초점 구동: 렌즈를 조금씩 움직이는 기능

`DriveLensEvf`는 렌즈를 무한한 거리값으로 지정하는 기능이 아니다. 현재 초점 위치에서
가까운 쪽 또는 먼 쪽으로 정해진 단계만큼 구동하도록 요청하는 기능이다. 따라서 앱은
“0.5 m에 맞추기”보다 “가까이 크게/가까이 작게/멀리 작게/멀리 크게”처럼 상대 이동 UI를
제공해야 한다.

권장 절차는 다음과 같다.

1. 라이브 뷰를 시작하고 확대 비율과 확대 영역을 표시한다.
2. 렌즈 상태와 원격 초점 구동 명령의 지원 여부를 시험한다.
3. 사용자가 방향과 단계 크기를 선택하면 한 번만 구동 명령을 보낸다.
4. 새 라이브 뷰 프레임에서 선명도를 확인한다. 길게 누르는 UI는 반복 명령 속도에 상한을 둔다.
5. 렌즈 끝 범위 또는 지원 안 됨 오류가 나면 반복을 멈추고 상태를 알려 준다.

카메라 메뉴의 MF와 SDK의 `DriveLensEvf`는 같지 않다. `DriveLensEvf`는 물리 초점 링을
돌리는 기능이 아니라, 카메라가 렌즈에 상대 이동을 요청하는 기능이다. 렌즈가 AF/MF
스위치나 focus-by-wire 동작을 어떻게 해석하는지는 렌즈·바디 조합에 좌우된다. 물리적으로
MF로 전환한 렌즈에서는 SDK 구동이 실패하거나 기대와 다르게 움직일 수 있으므로, 실제
사용하는 렌즈마다 시험 결과를 남긴다.

## 초점 위치 지정과 터치 AF

프레임의 특정 좌표에 AF를 요청하는 기능은 터치 패널 탑재 모델에만 한정될 수 있다. 캐논의
기능 개요도 “라이브 뷰의 지정 위치에서 AF 초점 위치 설정”에 이 제한을 명시한다. EOS
200D, 200D Mark II, 850D 모두 터치 패널을 갖지만, **EDSDK 패키지 버전·카메라 펌웨어·현재
AF 방식에서 해당 속성/명령이 실제 허용되는지**를 연결 후 확인해야 한다.

좌표 AF를 구현할 때에는 화면 픽셀을 그대로 카메라에 보내지 않는다. 먼저
`kEdsPropID_Evf_CoordinateSystem` 및 표시된 이미지 사각형을 읽고, 레터박스·회전·확대·UI
스케일을 제거한 뒤 EVF 좌표계로 변환한다. 좌표 변환이 틀리면 사용자가 누른 지점과 AF
프레임이 계속 어긋난다.

## 실패를 안전하게 다루는 법

| 증상 | 가능한 원인 | 대응 |
|---|---|---|
| AF 명령이 실패 | 라이브 뷰 꺼짐, 렌즈 AF 불가, 현재 모드 미지원 | 라이브 뷰·렌즈 스위치·AF 모드·허용값을 차례로 확인 |
| AF는 성공했으나 사진이 흐림 | 피사체 이동, 저대비, 셔터 지연, 얕은 심도 | 확대 확인 후 재AF, 조리개·셔터 속도 조정, 원격 미세 구동 |
| 수동 구동이 움직이지 않음 | 렌즈/상태 미지원, 끝 범위, MF 전환 | 오류 표시 후 반복 중지, 물리 링 조작 또는 다른 렌즈로 검증 |
| 누른 위치와 AF 위치가 다름 | 화면 좌표와 EVF 좌표가 다름 | 좌표계·이미지 사각형·확대 상태를 다시 계산 |
