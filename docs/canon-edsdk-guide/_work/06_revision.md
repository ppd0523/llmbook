# 구조 퇴고와 학습성 개선

## 구조와 학습성 기준

- 첫 페이지는 대상 독자, 기준 기종, 언어·구현 제외 범위, 웹캠의 의미를 분리해 보여 준다.
- 세션·이벤트를 촬영보다 앞에 배치해 “명령 성공 = 완료” 오해를 예방한다.
- 사진 전송에는 상태 흐름도가, 라이브 뷰에는 시작·종료 순서 목록이 있다.
- AF 설정·AF 실행·셔터 AF·상대 렌즈 구동을 한 표로 대비한다.
- 마지막 장에는 실제 장비에서 실행 가능한 기종·렌즈 승인 시험표가 있다.
- 용어는 “수동 초점 구동” 대신 “원격 초점 구동”으로 통일한다. `DriveLensEvf`가 물리 초점 링을 직접 조작하거나 절대 거리로 초점을 지정하는 기능이라는 오해를 줄이기 위해서다.
- “웹캠 라이브 뷰” 대신 “웹캠 영상원”이라고 써서 EVF 프레임 취득과 운영체제 UVC 웹캠 장치의 경계를 분명히 한다.

## 점검 결과

- 학습 목표와 각 장의 표·흐름·확인 질문이 대응한다.
- 새 용어는 첫 등장 문장에서 정의하거나 풀어썼다.
- 프로그래밍 코드와 언어별 절차는 최종 본문에 없다. `text` 블록은 1장과 3장의 상태 흐름도에만 쓴다.
