# 구조 퇴고와 학습성 개선

## 반영한 개선

- 첫 페이지에 대상 독자, 기준 기종, 언어·구현 제외 범위, 웹캠의 의미를 명확히 분리했다.
- 세션·이벤트를 촬영보다 앞에 배치해 “명령 성공 = 완료” 오해를 예방했다.
- 사진 전송과 라이브 뷰에 각각 상태 흐름도를 넣었다.
- AF 설정·AF 실행·셔터 AF·상대 렌즈 구동을 한 표로 대비했다.
- 마지막 장에 실제 장비에서 실행 가능한 기종·렌즈 승인 시험표를 넣었다.
- “수동 초점 구동”을 “원격 초점 구동”으로 통일했다. `DriveLensEvf`가 물리 초점 링을 직접 조작하거나 절대 거리로 초점을 지정하는 기능이라는 오해를 줄이기 위해서다.
- “웹캠 라이브 뷰”를 “웹캠 영상원”으로 바꿔, EVF 프레임 취득과 운영체제 UVC 웹캠 장치의 경계를 더 분명히 했다.

## 점검 결과

- 학습 목표와 각 장의 표·흐름·확인 질문이 대응한다.
- 새 용어는 첫 등장 문장에서 정의하거나 풀어썼다.
- 코드 블록과 프로그래밍 언어별 절차를 최종 본문에 넣지 않았다.
