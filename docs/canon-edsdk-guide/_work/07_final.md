# 기준 원고 확정 기록

이 파일은 기준 원고를 확정한 기록이며 원고 자체가 아니다(adr/0001). 기준 원고는 `docs/canon-edsdk-guide/`의 다음 MkDocs 챕터 본문이다.

1. `01-scope-and-compatibility.md`
2. `02-session-and-events.md`
3. `03-still-capture-and-transfer.md`
4. `04-live-view-and-webcam.md`
5. `05-autofocus-and-manual-focus.md` — 자동초점과 원격 초점 구동
6. `06-settings-video-and-troubleshooting.md`

최종 본문은 코드와 언어별 연동 방법을 제외하고, `EDSDK.dll`의 장치 제어 의미·상태·운용 순서만 다룬다. 외부 출처는 공식 캐논 자료를 우선하고, 2016 API 참조서와 공개 GitHub 헤더는 버전 조건을 표시해 보조 근거로 사용한다.
