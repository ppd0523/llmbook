# 작성 범위 정의

## 주제와 중심 질문

- 주제: Windows용 `EDSDK.dll`을 통한 Canon EOS 200D, EOS 200D Mark II, EOS 850D의 기능 중심 제어
- 중심 질문: 세 DSLR을 EDSDK로 촬영, PC 파일 전송, 라이브 뷰, AF, 렌즈 초점 구동까지 안전하게 운용하려면 어떤 상태와 순서를 지켜야 하는가?
- 해결할 문제: 공개 자료가 구버전 API 문서와 언어별 예제에 치우쳐 있을 때, 구현 언어와 무관하게 기능의 순서·완료 조건·기종 의존성을 판단하지 못하는 문제

## 독자 상태 진단

- 기준 독자: EDSDK를 처음 접하는 기술 담당자
- 알고 있다고 가정하는 지식: USB 카메라 연결, 사진·라이브 뷰·AF·셔터·메모리 카드의 기본 의미
- 모른다고 가정하는 개념: SDK 세션, 속성, 명령, 객체 이벤트, EVF, 저장 위치, 전송 완료, 참조 객체 수명
- 우선 학습 목적: 카메라 제어 제품의 요구사항 정리, 검증, 운영 설계
- 실패 가능 지점: EDSDK 라이브 뷰를 OS 웹캠으로 오해, 촬영 요청을 파일 전송 완료로 오해, AF 설정과 AF 실행을 혼동, 전송 완료/취소를 누락, 세 기종의 세부 기능을 동일하다고 가정

## 학습 목표

1. 카메라 검색·세션·이벤트·정리의 제어 수명 순서를 설명한다.
2. 사진의 저장 위치를 선택하고 PC 전송의 완료·취소 처리를 설계한다.
3. 라이브 뷰 JPEG 취득과 별도 웹캠 파이프라인의 책임을 구분한다.
4. 일회 AF, 셔터 반누름 AF, 상대 렌즈 구동을 구분해 알맞은 흐름을 선택한다.
5. EOS 200D, EOS 200D Mark II, EOS 850D에서 실제 속성·허용값·명령 결과로 기능을 검증한다.

## 포함 범위

- 세 기준 기종의 EDSDK 호환성 및 지역별 모델명
- SDK 수명, 카메라 세션, 객체·속성·상태 이벤트
- 정지 사진 촬영, 카드·PC 저장, 다운로드 완료·취소
- PC 라이브 뷰 프레임, 확대·좌표계, 웹캠 영상원 경계
- 라이브 뷰 AF, 셔터 AF, 렌즈 상대 초점 구동, 좌표 AF의 조건
- 촬영 설정, 동영상의 카드 저장·파일 전송, 장애 대응과 승인 시험

## 제외 범위

- C++, C#, .NET, Python 등 언어별 DLL 로딩·함수 선언·콜백·예제 코드
- EDSDK 설치·라이선스 신청·배포 패키지의 절차별 설명
- EOS Utility의 사용법 자체, HDMI 캡처 장치·가상 카메라 구현 방법
- 모든 EDSDK 상수와 모든 Canon 기종의 완전한 API 참조
- 자동 포커스 알고리즘, 렌즈 광학, 동영상 인코딩 구현
