# 구성 설계

## 설명 순서

1. 범위·호환성·제어 모델: 대상 기종, 경계, 객체·속성·명령·이벤트를 정의한다.
2. 연결 세션과 이벤트: 비동기 완료와 객체 수명을 설명한다.
3. 정지 사진 촬영과 파일 전송: 저장 위치, 셔터, 전송 완료를 Worked Example으로 다룬다.
4. 라이브 뷰와 웹캠 영상원: EVF 프레임과 UVC 웹캠의 차이, 시작·종료·프레임 루프를 설명한다.
5. 자동초점과 원격 초점 구동: AF 설정·실행·상대 렌즈 구동을 구분한다.
6. 설정·동영상·문제 해결: 허용값 조회 규칙, 승인 시험, 문제표, 출처를 제공한다.

## 개념 의존성

```text
호환성·세션·이벤트
  ├─ 저장 위치 → 촬영 → 전송 완료
  ├─ EVF 출력 장치 → 라이브 뷰 프레임 → AF/렌즈 구동
  └─ 속성 자료형·허용값 → 설정 변경·기종별 기능 확인
```

## 학습 목표 대응

| 학습 목표 | 본문 | 확인 장치 |
|---|---|---|
| 제어 수명 설명 | 1~2장 | 상태기계, 확인 질문 |
| PC 전송 설계 | 3장 | 전송 흐름도, 운영 정책 |
| 라이브 뷰·웹캠 경계 | 4장 | 경로 비교표, 점검표 |
| AF·수동 구동 구분 | 5장 | 기능 비교표, 실패표 |
| 세 기종의 실제 검증 | 1·5·6장 | 허용값 확인 원칙, 승인 시험표 |

## 오해 방지 계획

- “웹캠”은 EDSDK 프레임 원본이라는 뜻으로만 쓰고 UVC·가상 카메라와 구별한다.
- “수동 초점”은 앱이 절대 초점 거리를 설정하는 일이 아니라 상대 렌즈 구동임을 설명한다.
- 구버전 API 문서의 기능을 현재 세 기종에 무조건 적용하지 않고 실제 속성·명령 시험을 요구한다.
