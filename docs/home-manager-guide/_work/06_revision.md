# 독자 검증과 퇴고 기록

## 1. 독자 검증

- 검토자: 작성에 참여하지 않은 별도 서브에이전트
- 검토자에게 준 정보: `01_scope.md`의 대상 독자·선행지식, 정답 블록을 지운 `index.md`와 1~6장 사본, 본문이 링크하는 예제 구성 파일. 원본 챕터, `_work/`, 웹 검색은 쓰지 못하게 했다.
- 검토 대상: 전 장
- 실습형 명령 실행 여부: 실행하지 않았다. `switch`와 rollback이 검토 환경의 사용자 홈을 바꾸기 때문이다. 검토자는 실행할 명령과 기대 결과를 본문만으로 적었다.

검토자의 답은 모든 문항에서 정답과 방향이 같았다. 막힌 지점은 용어 미정의(사용자 프로필, 로그인 shell, `xdg.enable`), 다른 장에만 있는 규칙(attribute 생략), 배타적이지 않은 보기, 예제 README와 4.7절이 서로 반대로 읽히는 문제였다. 현재 본문 기준으로 열린 항목은 없다.

README와 4.7절의 불일치는 부모 링크 종류의 차이에서 왔다. 예제처럼 out-of-store link로 부모를 연결하면 build가 실패하고(README가 맞다), 일반 `source`이면서 같은 파일이 있으면 하위 선언이 무시된다. 4.7절 표가 두 경우를 함께 다룬다. 확인 결과는 `05_review.md`에 있다.

검토 중 3장 실습 4의 `~/.zshrc` 경로가 예제 구성에 없다는 기술 오류가 드러났다. 원인과 확인 결과는 `05_review.md`에 있다.
