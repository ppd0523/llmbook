# 초안 변경점

- 모든 독자가 알아야 할 기준을 index와 1장에 먼저 둔다.
- 옵션 설명에는 실제 예제 Flake의 파일 경로와 output 이름을 연결한다.
- 파일 충돌과 재귀 링크는 "어떻게 동작하는가"와 "안전한 선택은 무엇인가"를 함께 설명한다.
- 운영 절차에는 복구 가능성, version 조건, 좁은 범위의 input update를 추가한다.
- 문제 해결에는 `--show-trace` 사용 시점과 새 shell·세션 확인의 경계를 보강한다.
