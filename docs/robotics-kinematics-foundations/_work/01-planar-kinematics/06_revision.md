# 1단계 퇴고 계획 및 반영 내역

## 1. 퇴고 목표

- 구조: 문제 제기, 기초 용어, 회전, FK, 도달성, IK, 특이점 순으로 개념 의존성을 맞춘다.
- 학습성: 코사인 법칙과 $\theta_1$ 식이 완성 공식처럼 갑자기 등장하지 않게 한다.
- 누락 보강: 벡터, 기구학, 구성공간, 단위, `atan2` 반환 단위, 수치 경계를 설명한다.
- 용어 정리: 방위와 방향, 구성공간과 관절공간, $s_2$ 분기를 구별한다.
- 연습 개선: 도달성부터 두 IK 해와 FK 검산까지 수행하는 문제를 추가한다.
- 실습 개선: 본문 예제의 중간값과 검산 오차를 화면에서 확인하게 한다.

## 9. 2026-11-09 2차 퇴고: 절 역할과 과제 기준

| 기준 | 발견 | 조치 |

## 10. 2026-11-09 3차 퇴고: 남은 독자 지적 반영

9절에서 "반영하지 않은 지적"으로 남긴 8건을 사용자 요청으로 모두 반영했다.

| 위치 | 지적 | 조치 |
|---|---|---|
| 1절 | 구성공간·관절공간의 이중 용어 | 관절공간을 이 장의 용어로 정하고, 구성공간은 더 일반적인 이름이라고 한 번만 소개 |
| 2.2 | 세 성질의 근거 없음 | 기대 수준(확인할 수 있으면 됨)과 확인 방법(첫째 열 곱과 덧셈정리, $R(-\theta)=R(\theta)^T$) 추가 |
| 2.3 note | 두 쓰임의 차이를 보여 주는 예 없음 | $[1,0]^T$로 새 화살표와 같은 화살표를 비교하고, 전치가 반대 방향 변환임을 예로 보임 |
| 4.1 | 삼각형 조건에 등호를 포함하는 이유 없음 | 납작한 삼각형(완전 펴짐·접힘)이라는 설명 추가 |
| 4.2 그림 | $\theta_2$가 그림에 없음 | 링크 1의 연장선과 $\theta_2$, $\gamma+\lvert\theta_2\rvert=180°$를 그림에 추가 |
| 4.3 | "손의 위치"가 미지의 손인지 목표점인지 모호, 음의 분기 문장이 어려움 | "목표점에 닿은 손"으로 고치고, 음의 분기를 $s_2<0\Rightarrow\beta<0\Rightarrow\theta_1>\alpha$ 순서와 Worked Example 2 수치로 설명 |
| 4.3 | `atan2`를 쓰는 이유($\arccos$와 비교) 없음 | $\arccos$의 범위 $[0°,180°]$와 분기 처리 차이 설명 추가 |
| 5절 | 특이점 판정 기준이 감각적 | 이 팔에서는 $s_2=0$일 때만 특이점이고, 모두 경계 위에 있다는 기준 추가 |
