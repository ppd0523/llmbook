# 1단계 독자 검증과 퇴고 기록

## 1. 독자 검증

- 검토자: 별도 서브에이전트 1개
- 검토자에게 준 정보: 대상 독자(고등학교 행렬·삼각함수, 코사인 법칙은 모른다고 가정), 정답 블록을 지운 챕터 본문 사본, 본문이 쓰라고 지시하는 HTML 실습 2개(`fk-playground.html`, `ik-practice.html`). `_work/`는 주지 않았다.
- 방법: 본문만 읽고 연습문제 8개를 푼 뒤 정답과 대조했다. 실습은 브라우저 대신 소스를 읽어 본문의 지시와 대조하고, IK 풀이 코드를 Node.js로 돌려 본문 수치와 비교했다.
- 결과: 8문제 모두 정답과 일치했다. 실습의 FK·IK 수식과 도달성 판정은 본문과 같다.
- 남은 문제: 없다. 검토자의 지적은 모두 현재 본문과 실습에 반영되어 있다. 반영한 뒤의 본문으로 독자 검증을 다시 하지는 않았다.

## 2. 퇴고 목표

- 구조: 문제 제기, 기초 용어, 회전, FK, 도달성, IK, 특이점 순으로 개념 의존성을 맞춘다.
- 학습성: 코사인 법칙과 $\theta_1$ 식이 완성 공식처럼 갑자기 등장하지 않게 한다.
- 누락 보강: 벡터, 기구학, 구성공간, 단위, `atan2` 반환 단위, 수치 경계를 설명한다.
- 용어 정리: 방위와 방향, 구성공간과 관절공간, $s_2$ 분기를 구별한다.
- 연습 개선: 도달성부터 두 IK 해와 FK 검산까지 수행하는 문제를 둔다.
- 실습 개선: 본문 예제의 중간값과 검산 오차를 화면에서 확인하게 한다.

## 3. 구조 점검

- [x] 목표 좌표와 관절각의 차이에서 IK 필요성을 제기한다.
- [x] 기구학·링크·관절·자유도를 FK·IK 계산 전에 정의한다.
- [x] 벡터와 회전행렬 뒤에 링크 벡터 합으로 FK를 만든다.
- [x] 도달 가능성을 판정한 뒤 코사인 법칙과 `atan2`로 IK를 푼다.
- [x] IK 계산 절차는 `4.4 IK 계산 순서` 한 절에 모으고, 4.2·4.3절은 개념 설명만 맡는다.
- [x] 일반 해를 설명한 뒤 경계와 특이점을 비교한다.
- [x] 1단계의 2D 좌표계가 2단계의 3D 강체변환으로 연결된다.

## 4. 학습성 점검

- [x] 각 학습목표가 본문 절과 연습문제에 대응한다.
- [x] FK와 IK에 풀이 예제과 HTML 실습이 있다.
- [x] 도달 불가와 특이점의 반례·비교가 있다.
- [x] 두 IK 분기가 계산 오류가 아님을 수치로 보여 준다.
- [x] 연습문제는 본문에 설명된 수식과 가정만으로 풀 수 있다.
- [x] IK 결과를 FK로 검산하는 절차가 본문·문제·실습에 반복된다.
- [x] 7절 첫머리에 문제와 절의 대응, 계산기·반올림 기준이 있다.
- [x] IK 과제가 $c_2=0$인 경우(풀이 예제 2), $c_2=-1/2$이고 $\theta_1$이 음수인 해가 나오는 경우(문제 7), $c_2=1/4$이고 $x=0$이라 `atan2`가 필요한 경우(문제 8)를 함께 연습한다.
- [x] 본문의 실습 지시가 실습의 실제 조작·표시와 맞다. IK 연습은 $l_1=3$, $l_2=2$ 고정이라 7절에 실습으로 확인할 수 있는 문제(5·6·8번)를 밝힌다.
- [x] 모든 정답이 `??? note "정답 확인"` 블록에 있고 판단 근거나 계산 과정, 흔한 오답(회전 누락, 상대각 오류)을 알아보는 단서를 붙인다.
