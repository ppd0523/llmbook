# 작성 범위 정의

## 1. 주제

- 다룰 주제: 2관절 평면 매니퓰레이터의 좌표계, 순기구학, 해석적 역기구학
- 중심 질문: 원하는 평면 목표점에 손을 놓기 위해 두 관절각을 어떻게 계산하는가?
- 해결하는 문제: 6자유도 매니퓰레이터와 휴머노이드 전신 IK에 앞서, 관절각·좌표계·FK·IK의 입출력을 구분하고 직접 계산할 수 있게 한다.
- 기술 영역: 강체 기구학, 평면 회전, 좌표 변환, 해석적 IK

## 2. 독자 상태 진단

### 2.1 숙련도와 선행지식

- 기준 독자 수준: 일부 지식이 있는 초심자
- 반드시 아는 개념: $2\times2$ 행렬 곱셈, 삼각함수, 피타고라스 정리, 코사인 법칙
- 알고 있으면 좋은 개념: `atan2`의 사분면 처리, 라디안
- 모른다고 가정할 개념: 회전행렬, 좌표계, 동차변환, 매니퓰레이터, 특이점, Jacobian
- 선행지식으로 가정할 용어: 벡터, 행렬, 좌표, 각도, 사인, 코사인
- 처음 등장할 때 설명할 새 용어: 링크, 관절, 자유도, 2R, 자세, 순기구학(FK), 역기구학(IK), 회전행렬, 좌표계, 동차좌표, 동차변환, 특이점, Jacobian, 수치 IK

### 2.2 경험과 학습 목적

- 구현 경험: 요구하지 않음. 브라우저 기반 실습으로 수식의 결과를 확인한다.
- 이론 학습 경험: 고등학교 수학 수준을 가정한다.
- 우선 학습 목적: 개념 이해와 손계산 문제 풀이
- 다음 단계 학습 목적: 3차원 회전, 6자유도 팔의 pose, Jacobian 수치 IK, 휴머노이드 보행용 전신 IK로 확장한다.

### 2.3 실패 가능 지점

- 점의 좌표와 같은 점을 다른 좌표계에서 표현한 좌표를 혼동할 수 있다.
- $\theta_2$를 세계 기준 각으로 오해해 $\theta_1+\theta_2$를 빼먹을 수 있다.
- `atan` 대신 `atan2`를 사용해야 하는 이유와 IK의 두 해를 놓칠 수 있다.
- 도달 불가와 특이점을 같은 문제로 오해할 수 있다.
- 도와 라디안, 2D와 3D 회전 합성의 차이를 혼동할 수 있다.

## 3. 학습 목표

이 자료를 읽은 뒤 독자는 다음을 할 수 있어야 한다.

1. 2D 회전행렬로 벡터를 회전시키고, 회전의 합성·역회전을 계산한다.
2. 두 링크 길이와 두 관절각으로 2관절 팔의 손 위치를 FK 식으로 계산한다.
3. 목표점의 도달 가능 여부를 판정하고, 코사인 법칙과 `atan2`로 가능한 IK 해를 구한 뒤 FK로 검산한다.
4. IK의 복수 해와 특이점을 그림과 식으로 구별한다.

## 4. 범위

- 반드시 포함: 도·라디안 변환, 2D 회전행렬, 좌표계의 필요성, 관절공간·작업공간·자세의 구분, 동차좌표와 2D 동차변환, 2R 평면 팔 FK, 해석적 IK의 기하학적 유도, 도달 가능 조건, 복수 해, 특이점, Worked Example, 연습문제, 인터랙티브 HTML 실습
- 선택 포함: 3D·6자유도·휴머노이드로 가는 학습 경로
- 제외: PID·PD와 기타 제어기, 모터·센서, 동역학, 충돌 회피, 궤적 생성, Jacobian 유도와 수치 IK의 상세 구현
- 다음 장: 3D 회전행렬과 동차변환, 6자유도 pose, Jacobian 기반 수치 IK, 지지발·골반·스윙발 제약을 갖는 전신 IK

## 6. 성공 기준

- 독자가 $(3,2)$ 같은 목표점의 두 IK 해를 직접 구하고 FK로 검산한다.

- 독자가 완전 펴짐·완전 접힘을 도달 불가가 아닌 특이점으로 구분한다.
