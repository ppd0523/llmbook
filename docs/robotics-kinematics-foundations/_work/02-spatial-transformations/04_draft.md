# 2단계 초안 메모

## 서술 흐름

1단계에서 2차원 점에 회전과 이동을 적용했다. 2단계에서는 이를 3차원으로 확장한다. 첫 시도에서는 `Rx`, `Ry`, `Rz` 공식을 먼저 제시했으나, 학습자가 회전행렬의 열과 직교성 설명을 읽기 위해 내적·단위벡터가 필요하므로 벡터 보충을 앞에 배치한다.

핵심 예제는 모두 90° 회전과 정수 이동을 사용한다. 손계산으로 결과를 확인한 뒤 HTML 실습의 행렬과 그림으로 검산할 수 있게 한다.

## 초안에서 해결할 혼동

- `R v`가 물체를 돌리는 것인지 좌표 표현을 바꾸는 것인지 문맥 없이 쓰지 않는다.
- `^A R_B`는 B의 축을 A로 표현하고, B 좌표 벡터를 A 좌표로 옮긴다고 정의한다.
- 행렬곱은 오른쪽부터 적용된다는 문장을 모든 합성 예제 전에 반복한다.
- 동차좌표의 마지막 수가 점은 1, 방향은 0인 이유를 이동의 영향 여부로 설명한다.
- 역변환의 이동 성분을 `-p`로 잘못 쓰지 않도록 수치 예제를 포함한다.
- roll-pitch-yaw의 순서를 반드시 식과 함께 명시한다.

## 실습 초안

- 입력: roll, pitch, yaw, 회전 순서, x/y/z 이동, B 좌표 점
- 출력: 세계축과 B축, 변환된 점, `R`, `T`, `r_A`
- 프리셋: 항등, z축 90°+이동, 회전 순서 비교, 짐벌락
- 외부 라이브러리 없이 단일 HTML로 실행
