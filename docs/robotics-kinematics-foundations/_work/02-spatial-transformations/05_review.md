# 2단계 기술 검증

## 1. 검증 대상

- 정의: 자유도, 강체, 위치, 방위, 자세, 벡터, 내적, 직교, 회전행렬, 동차변환, 짐벌락
- 수식: 기본축 회전, 회전행렬 조건, 좌표 변환, 변환 합성, 역변환, Z-Y-X RPY
- 실습: 회전 순서, 점·방향벡터 비교, 회전행렬 검사, 짐벌락 프리셋
- 용어: 방위와 방향벡터의 구분, 좌표계 첨자, SO(3), SE(3)
- 가정과 단위: 열벡터, 오른손 좌표계, 길이 단위 통일

## 2. 검증 결과

미해결 기술 문제는 없다.

## 3. 가정 확인

| 가정 | 타당성 | 본문 반영 |
|---|---|---|
| 열벡터를 사용한다. | 로보틱스 교재에서 널리 쓰이며 본문의 오른쪽부터 적용 규칙과 일치한다. | 계산 규약에 명시 |
| 오른손 좌표계와 양의 오른손 회전을 사용한다. | 기본축 회전행렬의 부호를 하나로 고정한다. | 계산 규약과 2절에 명시 |
| 위치 좌표의 길이 단위는 모두 같다. | 회전된 점과 이동벡터를 더하려면 같은 단위가 필요하다. | 계산 규약과 7절에 명시 |
| 링크는 강체다. | 기구학 단계에서 링크 길이와 축 사이 관계를 고정하기 위한 기본 가정이다. | 도입부에 명시 |

## 4. 실행·계산 검증

| 계산 | 입력 | 기대 결과 | 확인 결과 |
|---|---|---|---|
| z축 90° 회전과 이동 | $\mathbf r_B=(1,0,0)$, $\mathbf p=(2,1,3)$ | $\mathbf r_A=(2,2,3)$ | 일치 |
| 방향벡터 변환 | $\mathbf d_B=(1,0,0)$, $\mathbf p$ 변경 | $\mathbf d_A=(0,1,0)$ 유지 | 일치 |
| 회전 순서 | roll 90°, yaw 90°, $\mathbf r_B=(1,0,0)$ | Z-Y-X는 $(0,1,0)$, X-Y-Z는 $(0,0,1)$ | 일치 |
| A-B-C 합성 | $\mathbf p_{BC}=(0,2,0)$ | $\mathbf p_{AC}=(0,1,3)$ | 일치 |
| 역변환 | $\mathbf r_A=(2,2,3)$ | $\mathbf r_B=(1,0,0)$ | 일치 |
| 짐벌락 | pitch 90°, roll=yaw=0°와 30° | 같은 회전행렬 | 일치 |

다음 값은 Python 스크립트로 계산해 본문과 일치함을 확인했다(uv, Python 3.14).

- 짐벌락 유도식 $R_z(\psi)R_y(90°)R_x(\phi)$의 일반형, 중간 곱 $R_y(90°)R_x(\phi)=R_z(-\phi)R_y(90°)$, 항등식 $R_z(\psi)R_y(90°)R_x(\phi)=R_z(\psi-\phi)R_y(90°)$. 네 가지 $(\phi,\psi)$ 조합으로 수치 확인
- 연습문제 5($R^TR=I$ 판정, $Q$·$S$ 판정값), 6(회전 순서, $R_x$·$R_y$), 8(7번 결과의 역변환)의 답과 해설 값
- 연습문제 9의 ${}^AT_C$: 회전부 $R_z(90°)R_x(90°)$, 위치 $(2,2,3)$, 순서를 뒤집었을 때 위치 $(3,-3,1)$
- 판정 순서의 $ad-bc$ 규칙: x·y·z 어느 축을 고정해도 성립하고, 축 맞바꿈은 $-1$이다. 규칙은 대각선 위의 1에만 적용한다. 예를 들어 $\begin{bmatrix}0&1&0\\0&0&1\\1&0&0\end{bmatrix}$의 행렬식은 $+1$인데, 1행 2열의 1을 기준으로 남은 네 성분에 $ad-bc$를 쓰면 $-1$이 나온다.
- 8절 역변환의 중간값 $R^T[2,1,3]^T=[1,-2,3]^T$, $-R^T\mathbf p=[-1,2,-3]^T$
- 12절 3번: $R_x(90°)$의 세 열 $[1,0,0]^T$, $[0,0,1]^T$, $[0,-1,0]^T$. 4번: $\operatorname{diag}(-1,-1,1)$은 $M^TM=I$, $\det M=+1$이고 $R_z(180°)$와 같다.
- 9절의 $R_z(-\phi)R_y(90°)=R_y(90°)R_x(\phi)$를 두 가지 $\phi$로 수치 확인
- 실습의 회전행렬 검사는 열 길이 세 개, 서로 다른 두 열의 내적 세 개, $R^TR-I$ 최대 오차, $\det R$를 표시한다(코드 확인). 점과 방향의 식은 본문 규약대로 ${}^A\mathbf r$, ${}^B\mathbf r$ 꼴의 왼쪽 위첨자로 쓴다.
- $R_x(90°)$: $+y\to+z$, $+z\to-y$, $R_y(90°)$: $+z\to+x$, $+x\to-z$
- 2절의 내적 전개식

## 5. 수식 검증

| 수식 | 의미와 단위 | 검증 상태 |
|---|---|---|
| $R_x$, $R_y$, $R_z$ | 오른손 능동 회전, 무차원 | 부호 확인 |
| $R^T R=I$, $\det R=1$ | 정규직교성과 반사 배제 | 확인 |
| ${}^A\mathbf r={}^A R_B{}^B\mathbf r+{}^A\mathbf p_B$ | 점과 이동은 같은 길이 단위 | 확인 |
| ${}^A T_C={}^A T_B{}^B T_C$ | 좌표계 첨자와 곱 순서 | 수치 예제로 확인 |
| $T^{-1}=[R^T,-R^T\mathbf p;0,1]$ | 반대 좌표 변환 | 수치 예제로 확인 |
| $R=R_z(\psi)R_y(\theta)R_x(\phi)$ | 이 장의 Z-Y-X 규약 | 확인 |

## 7. 남은 위험

- 브라우저와 수식 렌더러에 따라 위 첨자 좌표계 표기의 간격이 조금 다르게 보일 수 있다.
- 3D 그림은 2D 등각 투영이므로 화면상의 각도와 길이만으로 수치를 판정하면 안 된다. 본문에 이 제한을 명시한다.
- RPY의 고정축·움직이는 축 해석은 이 장의 범위를 넘으므로 수식 자체를 규약으로 고정했다.
