# 2단계 개요

1. 왜 3D 자세가 필요한가
   - 6자유도: 위치 3 + 방향 3
   - 좌표계와 강체 정의
2. 필요한 벡터 도구
   - 열벡터, 길이, 단위벡터, 내적, 직교
   - 오른손 좌표계와 회전 방향
3. 세 기본 회전행렬
   - `Rx`, `Ry`, `Rz`
   - Worked Example: z축 90° 회전
4. 회전행렬을 읽는 법
   - 열은 회전된 축
   - `R^T R=I`, `det R=1`
   - 전치행렬이 역행렬
5. 회전의 합성과 순서
   - 오른쪽부터 적용
   - Worked Example: `Rz Rx`와 `Rx Rz`
6. 회전인가 좌표 변환인가
   - 능동 회전과 좌표 표현 변환
   - `^A R_B` 첨자 규칙
7. 4×4 강체변환
   - 자세, `^A T_B`, 점 `w=1`, 방향 `w=0`
   - Worked Example: B의 점을 A로 변환
8. 변환 체인과 역변환
   - 첨자 소거, 변환 합성
   - `T^-1=[R^T,-R^T p;0,1]`
9. Roll-pitch-yaw 입문
   - Z-Y-X 규약
   - 짐벌락은 로봇의 고장이 아닌 표현의 특이점
10. 인터랙티브 실습
11. 흔한 실수
12. 연습문제와 정답
13. 6자유도 매니퓰레이터로 연결
14. 요약, 추가 읽을거리, 참고문헌
