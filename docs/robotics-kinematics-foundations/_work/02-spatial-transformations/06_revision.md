# 2단계 독자 검증과 퇴고 기록

## 1. 독자 검증

- 검토자: 별도 서브에이전트 1개
- 검토자에게 준 정보: 대상 독자(1단계 학습, 내적·행렬식은 모른다고 가정), 정답 블록을 지운 1·2장 본문 사본, 본문이 쓰라고 지시하는 HTML 실습(`spatial-transform-lab.html`). `_work/`는 주지 않았다.
- 방법: 본문만 읽고 연습문제 10개를 푼 뒤 정답과 대조했다. 실습은 브라우저 대신 소스를 읽고, 계산 코드를 Node.js로 옮겨 10절 다섯 단계의 기대 결과와 비교했다.
- 결과: 10문제 모두 정답과 일치했다. 10절 다섯 단계의 기대 결과(풀이 예제 3의 행렬과 점 $(2,2,3)$, +y와 +z로 갈라지는 회전 순서, 이동에 영향받지 않는 방향벡터, pitch 90°에서 roll·yaw 30°의 같은 행렬)가 실습 코드에서 그대로 나온다.
- 남은 문제: 없다. 검토자의 지적은 모두 현재 본문과 실습에 반영되어 있다. 반영한 뒤의 본문으로 독자 검증을 다시 하지는 않았다.

## 2. 퇴고 목표

- 구조: 선수 지식에서 벡터, 회전, 좌표 변환, 강체변환, RPY로 이어지는 의존 순서를 분명히 한다.
- 학습성: 추상적인 합성과 짐벌락 뒤에 손으로 검산 가능한 수치 예를 둔다.
- 누락 보강: 단위, 행렬식 계산 단서, 변환 합성 직접 문제를 둔다.
- 중복 제거: orientation과 direction에 섞여 쓰인 `방향`을 방위와 방향벡터로 구분한다.
- 실습 개선: 본문의 점·방향벡터 차이와 짐벌락 예제를 그대로 재현하게 한다.
- 범위: 행렬식이 손잡이 방향을 판별한다는 사실은 부호 있는 평행육면체 부피로 직관만 설명하고, 증명은 범위 밖으로 둔다.

## 3. 구조 점검

- [x] 문제 제기가 6자유도 자세 표현이라는 학습 목표와 연결된다.
- [x] 손바닥과 발바닥 예가 추상적인 방위 정의보다 먼저 또는 함께 나온다.
- [x] 벡터 도구 뒤에 회전행렬, 회전행렬 뒤에 강체변환이 나온다.
- [x] 회전행렬 판정 방법은 4절의 절차 소단원 `회전행렬인지 판정하는 순서`에 모으고, 4절의 나머지는 개념 설명만 맡는다.
- [x] 좌표계 첨자를 정의한 뒤 변환 합성과 역변환에 사용한다.
- [x] RPY 규약을 정의한 뒤 짐벌락을 설명한다.
- [x] 10절 인터랙티브 실습은 과제 역할만 맡는다.
- [x] 새 용어가 다른 미정의 전문 용어에 의존하지 않는다.

## 4. 학습성 점검

- [x] 모든 학습목표가 본문 절과 연습문제에 대응한다.
- [x] 세 기본축 회전, 회전 순서, 점 변환, 변환 합성에 풀이 예제이 있다.
- [x] 정규직교행렬이지만 회전이 아닌 반사 반례가 있다.
- [x] 능동 회전과 좌표 표현 변환을 비교한다.
- [x] 점과 방향벡터를 같은 입력으로 비교한다.
- [x] 짐벌락을 두 개의 구체적인 RPY 조합으로 확인한다.
- [x] 흔한 실수와 해결 방법이 별도 표에 정리되어 있다.
- [x] 연습문제 10개가 절 순서대로 놓이고, 12절 첫머리에 문제와 절의 대응이 있다.
- [x] 변환 체인 문제(9번)는 ${}^BT_C$에 x축 90° 회전을 넣어 풀이 예제 4의 이동만 있는 체인과 다른 조건을 연습한다.
- [x] 모든 정답이 `??? note "정답 확인"` 블록에 있고 근거가 있다.
