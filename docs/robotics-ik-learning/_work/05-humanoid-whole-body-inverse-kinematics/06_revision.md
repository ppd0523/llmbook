# 5단계 퇴고 계획 및 반영 내역

## 퇴고 목표

- 4단계의 다중 과제 예고에서 휴머노이드 모델로 자연스럽게 이동한다.
- 트리·부유 베이스·접촉·과제 계층을 새 용어가 필요한 순서대로 설명한다.
- 가중치의 한계를 충돌 반례로 먼저 경험한 뒤 엄격한 우선순위를 도입한다.
- 영공간 수식을 두 변수 손계산으로 검산할 수 있게 한다.
- 등식과 부등식, 사후 클리핑과 풀이 내부 제약을 분리한다.
- CoM·지지 다각형을 locomotion과 연결하되 동적 안정성을 주장하지 않는다.
- 실습에서 같은 목표에 대한 두 방법을 나란히 비교한다.

| 위치 | 발견한 학습성 문제 | 반영 내용 |
|---|---|---|

| 1~2절 | 한 문단에 트리 구조와 영향 범위 설명이 겹쳤다. | 직렬 체인·기구학 트리의 정의와 가지별 영향을 짧은 문단으로 나눴다. |
| 3절 | 구성, 단위 쿼터니언과 업데이트 단위가 설명 없이 등장했다. | 전신 구성의 한 문장 정의, 단위 쿼터니언의 저장값·자유도 차이, m·rad 단위를 추가했다. |
| 4절 | 위치와 방위 단위 설명의 조사가 어색했다. | 두 단위를 먼저 분리해 밝힌 뒤 수치 크기를 맞추는 이유를 설명했다. |
| 5~6절 | 랭크와 역할 이름인 ‘제약’이 독자에게 모호했다. | 랭크를 독립 조건 수와 연결하고, 역할 분류와 수학적 등식·부등식을 구분했다. |
| 12~14절 | 등식 영공간 방식과 부등식 제약 최적화의 적용 경계가 한 문장에 섞였다. | HQP를 유일한 방법처럼 표현하지 않고 대표 방법으로 한정했으며 활성 제약을 정의했다. 반복 알고리즘에서도 접촉 등식과 관절 제한 부등식을 분리했다. |
| 16절 | 볼록 영역과 후속 locomotion 용어가 정의 없이 등장했다. | 볼록 영역의 판별 기준과 ZMP·캡처 포인트·센트로이달 모멘텀의 한 문장 정의를 추가했다. |
| 17절·HTML | 좌표축, 단위, 스텝 제한과 관절 제한 처리 방식이 실습 화면만으로 분명하지 않았다. | x·y 방향, m·° 단위, 베이스 이동 상한, 반복 클램프·접촉 재보정과 HQP의 차이를 화면에 명시했다. |
