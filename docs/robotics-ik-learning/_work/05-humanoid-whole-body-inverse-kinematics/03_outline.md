# 5단계 구성 설계

## 장의 한 문장 요약

휴머노이드의 부유 베이스와 전신 관절을 하나의 변수로 묶고, 지지발 접촉을 보존하면서 스윙발·골반·자세 과제를 우선순위에 따라 푸는 기구학적 전신 IK를 구성한다.

## 중심 질문

> 바닥에 닿은 발을 움직이지 않게 유지하면서 골반과 스윙발 목표를 전신에 분배하고, 목표가 충돌할 때 높은 과제를 보존하려면 어떤 변수·자코비안·우선순위가 필요한가?

## 학습 흐름

```text
6R 직렬 팔과 휴머노이드 비교
→ 기구학 트리와 부유 베이스
→ 지지발·스윙발·골반·CoM·자세 과제
→ 가중 누적의 타협과 한계
→ 영공간 기반 엄격한 우선순위
→ 관절 제한 부등식과 HQP의 필요성
→ 반복 전신 IK와 접촉 전환
→ 정적 기하와 동적 보행의 경계
→ 실습·연습·요약
```

## 섹션 구조

| 번호 | 섹션 | 목적 | 선행개념 | 산출되는 이해 |
|---|---|---|---|---|
| 1 | 한 손 대신 온몸의 여러 프레임을 맞추기 | 전신 IK 문제 제기 | 4단계 수치 IK | 여러 과제가 한 전신 변수를 공유한다. |
| 2 | 직렬 체인에서 기구학 트리로 | 휴머노이드 구조 설명 | 변환 체인 | 프레임별 FK와 자코비안을 구성한다. |
| 3 | 부유 베이스와 일반화 좌표 | 세계에 고정되지 않은 몸통 모델 | 6D 자세 | 베이스 변수와 관절변수를 구분한다. |
| 4 | 접촉을 가장 먼저 지키기 | 지지발 과제와 지지 상태 | 자코비안 | $J_s\Delta q=0$의 뜻을 읽는다. |
| 5 | 전신 과제 만들기 | 발·골반·CoM·자세 오차 구성 | 6D 오차 | 과제마다 $e_i,J_i$를 짝짓는다. |
| 6 | 가중 최소제곱 | 여러 과제 동시 누적 복습 | DLS | 유한 가중치는 타협임을 안다. |
| 7 | 엄격한 과제 우선순위 | 영공간 투영 유도 | 의사역행렬·영공간 | 낮은 과제가 높은 과제를 바꾸지 않는다. |
| 8 | Worked Example 1 | 2변수 투영 손계산 | 7절 | $J_1N_1=0$을 직접 검산한다. |
| 9 | 등식과 부등식 | 관절 제한의 올바른 형태 | 행렬 부등식 | 사후 클리핑의 위험을 설명한다. |
| 10 | Worked Example 2 | 목표 충돌·관절 제한 비교 | 9절 | 가중 타협과 우선순위 선택을 비교한다. |
| 11 | 여러 단계와 HQP | 재귀 알고리즘과 심화 연결 | 7~10절 | 과제 계층과 솔버 역할을 구분한다. |
| 12 | 반복 전신 IK | 전체 계산 순서와 종료 상태 | 4단계 반복 IK | 단계별 잔차를 보고 실패를 진단한다. |
| 13 | 단일·이중 지지와 접촉 전환 | locomotion 단계 연결 | 접촉 과제 | 지지 상태가 과제 구성을 바꾼다. |
| 14 | CoM와 지지 다각형의 경계 | 정적 기하 직관과 동역학 분리 | CoM | IK가 보장하지 않는 것을 안다. |
| 15 | 인터랙티브 실습 | 두 해법과 지지 상태 비교 | 전체 | 수치와 그림으로 드리프트를 관찰한다. |
| 16 | 흔한 실수 | 오류 예방 | 전체 | 좌표계·단위·우선순위 오류를 고친다. |
| 17 | 직접 해보기 | 목표별 평가 | 전체 | 손계산·비교·디버깅을 수행한다. |
| 18 | 요약과 다음 학습 | 지식 고정 | 전체 | 동적 locomotion 선행 경계를 안다. |

## 위험 구간과 처리

- 부유 베이스 자세 좌표와 속도 차원: 개념 벡터임을 밝히고 쿼터니언 구현은 제외한다.
- 접촉 고정과 힘 보장 혼동: 4절과 14절에서 두 번 경고한다.
- 2순위 식의 잔차 $e_2-J_2\Delta q_1$ 누락: Worked Example에서 각 항을 따로 계산한다.
- DLS 투영을 정확한 영공간으로 오해: 이상적 식과 실습의 작은 감쇠 근사를 구분한다.
- CoM 지표 과대해석: 정지·준정적 직관임을 명시하고 MIT 보행 자료로 동역학 필요성을 연결한다.
- ‘control’이 포함된 원 논문과 사용자 제외 범위 충돌: 기구학 수준 수식만 채택하고 토크·피드백 부분은 사용하지 않는다.
