# 3단계 퇴고 계획 및 반영 내역

## 퇴고 목표

- 2단계의 강체변환에서 관절 변환, 직렬 체인, 6R FK, DH 순으로 자연스럽게 이어지게 한다.
- DH 용어가 정의보다 먼저 등장하지 않게 하고, 네 매개변수를 동작 순서와 연결한다.
- 추상적인 누적 곱 뒤에 정수 좌표의 6R 예와 익숙한 2R DH 예를 배치한다.
- 6자유도, 6R, 모든 자세 도달 가능성 사이의 잘못된 등식을 제거한다.
- 손목 중심과 TCP를 실습에서 따로 표시해 도구 오프셋의 효과를 보강한다.
- 1·2단계에서 이어지는 용어와 기호가 새 의미와 충돌하지 않게 한다.
- 홈 자세와 IK 목표 좌표계를 정의해 다음 단계로 넘어갈 때 전제가 빠지지 않게 한다.

## 변경 계획과 결과

| 위치 | 변경 전 위험 | 변경 방향 | 결과 |
|---|---|---|---|
| 도입 | 행렬곱부터 시작하면 목적을 놓친다. | $\mathbf q$ 입력과 자세 출력의 함수로 FK를 먼저 설명 | 반영 |
| 1절 | task space와 workspace를 같은 한국어로 쓰면 두 개념이 겹친다. | 말단 자세 공간과 작업공간으로 용어 분리 | 반영 |
| 2절 | 링크·관절·말단 용어가 한꺼번에 나온다. | 물리 구성요소 뒤에 좌표계 용어를 배치 | 반영 |
| 3절 | $3\times3$ 회전행렬과 $4\times4$ 회전 변환을 모두 $R$로 쓰면 크기가 모호하다. | $R$과 $\operatorname{Rot}$ 표기를 분리 | 반영 |
| 3~5절 | DH 없이 쓴 체인이 임시 기법처럼 보인다. | 기본 변환 체인을 하나의 완전한 모델링 방법으로 설명 | 반영 |

| 9절 | 새 DH 표를 검증할 기준이 없다. | 1단계 2R FK와 정확히 일치하는 Worked Example 사용 | 반영 |

| 11절 | 최종 숫자만 확인하고 홈을 모든 관절값 0으로 단정한다. | 홈 자세 정의, 중간 프레임, 회전행렬, 단위 검사 목록 제공 | 반영 |
| 12절 | 손목 관절은 위치와 무관하다고 과도하게 단순화한다. | 손목 중심과 TCP를 분리하고 오프셋 조건 명시 | 반영 |
| 12절 | 목표가 플랜지인지 TCP인지 불분명하다. | 기본 IK 식을 TCP 목표로 쓰고 프레임별 식을 구분 | 반영 |
| 12절 | 유효한 FK와 비특이 자세를 같은 조건으로 생각한다. | 교육용 홈의 손목 특이점을 별도로 설명 | 반영 |
| 실습 | 관절 효과를 분리해 보기 어렵다. | 팔 자세와 같은 팔 자세+손목 회전 프리셋 제공 | 반영 |
