# 3단계 기술 검증

## 검증 대상

- 정의: 열린 직렬 사슬, R/P 관절, 6R, 말단장치, 플랜지, TCP, 관절공간, 말단 자세 공간, 작업공간, FK, 홈 자세, 표준 DH
- 수식: 관절 변환, 6R 변환 체인, 표준 DH 행렬, 2R DH 곱, 베이스·도구 합성
- 예제: 교육용 6R 정수 좌표 예, 2R DH 유도
- 실습: 여섯 관절 슬라이더, 누적 변환, 손목 중심과 TCP, 회전행렬 유효성
- 가정: 강체 링크, 이상적인 관절, 열벡터, 오른손 좌표계, 동일 길이 단위

## 남은 위험

- DH 좌표계는 평행하거나 교차하는 축에서 둘 이상의 일관된 선택이 가능하다. 서로 다른 표만 보고 오답이라고 판정하지 않도록 최종 $T$와 규약을 함께 비교해야 한다.
- 교육용 3D 그림은 2D 투영이므로 화면상의 길이나 각도로 수치를 판정하지 않는다.
- 이 장은 이상적인 기구 모델만 다루므로 실제 로봇의 영점 오프셋과 제작 오차를 자동으로 설명하지 않는다.

## 검증 결론

핵심 정의, 표준 DH 행렬, 2R 유도, 6R 수치 예와 도구 변환에 미해결 기술 오류가 없다. 최종 퇴고에서 task space와 workspace, $3\times3$ 회전행렬과 $4\times4$ 회전 변환, 손목 중심 프레임과 플랜지 프레임의 경계를 명시했다. 특정 6R 구조의 일반화, DH 규약 혼합, 플랜지와 TCP 혼동을 막는 적용 조건도 본문에 반영했다.
