# 4단계 범위 정의

## 핵심 질문

현재 관절 자세에서 관절의 작은 변화가 말단의 작은 움직임으로 바뀌는 관계를 어떻게 행렬로 나타내고, 그 관계를 반복해서 사용해 목표 자세에 가까워지는 수치 역기구학을 어떻게 구성하고 검산하는가?

## 대상 독자와 선수 지식

- 고등학교 수준의 행렬 곱셈과 삼각함수를 안다.
- 1단계 `평면 회전과 2관절 IK`, 2단계 `3D 회전과 강체변환`, 3단계 `6자유도 매니퓰레이터의 순기구학`을 학습했다.
- 미분, 편미분, 벡터 외적, 행렬의 랭크, 의사역행렬은 모른다고 가정한다.
- 코드 구현 경험은 요구하지 않는다. 브라우저 실습에서 알고리즘의 한 단계를 관찰한다.
- 최종 목적은 6자유도 매니퓰레이터와 휴머노이드 전신 IK를 배우기 위한 기구학 기반을 갖추는 것이다.

## 학습 목표

학습자는 이 장을 마친 뒤 다음을 할 수 있어야 한다.

1. 변화량, 변화율, 편미분을 2R 순기구학의 기울기와 연결한다.
2. 2R 위치 자코비안을 유도하고 $\Delta\mathbf p\approx J\Delta\mathbf q$를 계산한다.
3. 자코비안의 각 열을 한 관절만 단위만큼 움직였을 때의 말단 운동으로 해석한다.
4. 유한차분으로 해석적 자코비안을 검산한다.
5. 자코비안 열의 독립성과 특이 자세의 관계를 설명한다.
6. 역행렬, Moore–Penrose 의사역행렬과 감쇠 최소제곱의 역할을 구별한다.
7. 감쇠 최소제곱을 이용한 수치 IK의 반복 절차와 종료 조건을 구성한다.
8. 회전관절과 직동관절의 3D 기하 자코비안 열을 읽는다.
9. 위치 오차와 방위 오차를 같은 좌표계에서 결합할 때 필요한 단위와 가중치 조건을 설명한다.
10. 휴머노이드의 여유 자유도와 영공간이 전신 IK에 왜 필요한지 설명한다.

## 포함 범위

- 라디안, 변화량 벡터, 벡터 크기, 한 변수의 변화율과 편미분의 입문적 설명
- $\Delta\mathbf x\approx J\Delta\mathbf q$와 $\dot{\mathbf x}=J\dot{\mathbf q}$의 구분
- 평면 2R 위치 자코비안의 직접 유도
- 자코비안 열벡터의 기하학적 의미와 유한차분 검산
- 2R 자코비안의 행렬식, 독립 방향과 특이 자세
- 정사각 역행렬의 한계와 Moore–Penrose 의사역행렬의 최소제곱·최소 크기 해석
- Jacobian transpose와 감쇠 최소제곱(DLS)의 비교
- DLS 기반 반복 수치 IK, 스텝 제한, 종료·정체·도달 불가 판정
- 3D 외적과 회전·직동관절의 기하 자코비안 열
- 6차원 말단 속도 벡터와 위치·방위 오차의 기초
- 위치와 방위의 단위·좌표계 일치, 가중치
- 휴머노이드 전신 IK를 위한 여유 자유도, 영공간과 다중 과제의 예고
- 독립 실행형 2R 수치 IK HTML 실습과 연습문제

## 제외 범위

- PID·PD 제어와 모든 제어기 설계
- 힘, 토크, 질량, 관성, 중력과 자코비안 전치의 정역학적 해석
- 모터 명령, 실시간 제어 주기와 하드웨어 구현
- SVD, 고유값 분해와 조작성 타원체의 상세 계산
- 회전군 로그, 지수좌표, twist·screw 이론의 정식 전개
- 해석적 6R IK 전체 해법
- 충돌 회피, 경로·궤적 계획과 시간 매개화
- 우선순위 기반 전신 IK와 접촉 제약의 전체 알고리즘
- 질량중심과 ZMP를 이용한 보행 안정성

## 성공 기준

- 학습자가 2R FK를 편미분해 $2\times2$ 자코비안을 만든다.
- 학습자가 한 관절 변화가 만드는 말단 변화와 자코비안 한 열을 연결한다.
- 학습자가 일반 자세와 특이 자세에서 열벡터 방향을 비교한다.
- 학습자가 DLS 한 번의 업데이트를 계산하고 반복 수치 IK 의사코드를 읽는다.
- 학습자가 실습에서 정상·특이 근처·도달 불가 목표를 비교하고 종료 이유를 설명한다.
- 학습자가 6R 또는 여유 자유도 로봇에서 자코비안의 크기와 각 열의 의미를 설명한다.
