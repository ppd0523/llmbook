# 4단계 퇴고 계획 및 반영 내역

## 퇴고 목표

- 미분을 모르는 독자가 FK에서 자코비안으로 자연스럽게 이동하게 한다.
- 기호 정의보다 행렬 공식이 먼저 나오지 않게 한다.
- 자코비안을 편미분 표가 아니라 관절별 말단 운동의 모음으로 읽게 한다.
- 특이점의 기하 직관을 먼저 제시한 뒤 역행렬의 한계를 설명한다.
- 정상 자세와 특이 자세의 수치 예를 나란히 제공한다.
- 2R 위치 IK의 단순한 예에서 6R 자세 IK와 휴머노이드 전신 IK의 전제로 확장한다.
- 수치 IK, 제어, 동역학의 범위를 분리한다.
