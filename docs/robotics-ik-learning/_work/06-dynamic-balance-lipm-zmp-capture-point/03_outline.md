# 6단계 구성 설계

## 1. 장의 한 문장 요약

한 시점의 전신 IK에서 시간에 따른 CoM 상태와 지면반력으로 이동하고, LIPM·ZMP·캡처 포인트로 현재 발 안에서 멈출 수 있는지를 판단한다.

## 2. 중심 질문

> CoM 위치만 보는 정적 판단을 속도·가속도와 지면반력까지 확장하여, 현재 지지 영역에서 멈출 수 있는지 또는 새 발 위치가 필요한지를 어떻게 판단하는가?

## 3. 학습 흐름

1. IK 자세 한 장면
2. 시간축을 가진 상태·궤적
3. 속도·가속도
4. 외력과 전신 CoM 동역학
5. 지면반력·모멘트
6. CoP와 ZMP
7. LIPM 축소와 요구 CoP
8. 캡처 포인트와 발걸음 필요 판단
9. 접촉 전환
10. 전신 IK로 목표 전달

| 새 용어 | 먼저 설명할 내용 | 첫 등장 | 설명 방식 |

| 속도·가속도 | 시간 간격 | 2절 | 유한차분 표 |

- 프리셋: 정지, 현재 발 안에서 회복, 한 걸음 필요, 같은 위치·빠른 속도

## 8. 위험 구간

- ZMP와 CoP 구분을 장황하게 만들어 흐름을 끊지 않는다.
- 3D 외적 대신 2D 모멘트부터 설명한다.
- 쌍곡함수 해는 필수 계산에서 제외하고 CP 1차 미분식으로 해석한다.
- CP가 지지 영역 안이라는 조건을 실제 로봇 안정성의 충분조건으로 단정하지 않는다.
- 실습의 수치 적분과 실제 제어를 구분한다.
