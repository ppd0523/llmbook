# 구성 설계

## 1. 장의 한 문장 요약

2관절 평면 팔을 이용해 회전행렬과 좌표계를 도입한 뒤, FK에서 IK로 입력·출력을 뒤집어 해석적 해와 한계를 이해한다.

## 2. 학습 흐름

```text
손을 목표점에 놓는 문제 -> 링크·관절 -> 회전 -> 좌표계와 변환 -> FK -> IK -> 도달 조건·두 해·특이점 -> 실습과 연습
```

## 3. 섹션 구조

| 번호 | 섹션 | 목적 | 필요한 선행개념 | 산출되는 이해 |
|---|---|---|---|---|
| 1 | 문제와 로봇 모델 | IK의 입출력과 관절공간·작업공간 구분 | 좌표 | 2R 팔의 변수와 목표 공간 |
| 2 | 회전과 좌표계 | $\theta_1+\theta_2$의 이유 | 삼각함수·행렬 | 회전행렬과 표현 좌표의 구분 |
| 3 | FK | 관절각에서 손 좌표 계산 | 회전 | FK 식을 계산 |
| 4 | IK | 목표점에서 관절각 계산 | 코사인 법칙 | 두 해를 계산 |
| 5 | 한계와 검산 | 오답 방지 | FK·IK | 도달 조건·특이점 구분 |
| 6 | 연습과 다음 경로 | 학습 목표 확인 | 본문 전체 | 6자유도·휴머노이드로의 연결 |

## 4. 개념 의존성

| 개념 | 먼저 알아야 할 개념 | 첫 등장 | 설명 방식 |
|---|---|---|---|
| 링크·관절·자유도 | 좌표 | 로봇 모델 | 2R 팔 그림 |
| 회전행렬 | 사인·코사인, 행렬 곱 | 회전 | x축 단위벡터 회전과 3D 회전과의 차이 |
| 좌표계 | 회전행렬 | 좌표계 | 같은 화살표를 다른 축으로 읽기 |
| 동차좌표·동차변환 | 좌표계·행렬 곱 | 좌표계 | B의 점 하나를 A 좌표로 바꾸는 계산 예제 |
| FK | 각의 누적 | FK | 링크 끝 벡터 두 개의 합 |
| IK | FK·코사인 법칙 | IK | 목표·링크가 만드는 삼각형과 $\alpha-\beta$ 분해 |
| 특이점 | IK 해 | 한계 | 완전 펴짐·접힘 비교 |
| 관절공간·작업공간·자세 | 좌표·2R 팔 | 로봇 모델 | 위치·방향·관절각의 역할 비교 |

## 5. 예제와 실습

- Worked Example: 목표 $(3,2)$의 FK와 IK를 모두 계산한다.
- 실습 1: FK 놀이터에서 $\theta_1=30°$, $\theta_2=60°$를 설정한다.
- 실습 2: IK 연습에서 점선 작업공간 경계와 $(5,0)$, $(1,0)$, $(5.5,0)$를 비교한다.
- 직접 풀이: 회전, FK, IK, 도달 가능, 특이점의 다섯 문제와 정답을 제공한다.

## 6. 위험 구간

- `atan2`는 사분면까지 고려한다는 한 문장 설명과 두 해를 함께 제시한다.
- 팔꿈치 해는 위·아래 대신 $s_2$의 부호로 구분해 좌표계에 따른 명칭 혼동을 피한다.
- 특이점은 제어 문제가 아니라 기구학적 자세의 성질로만 설명한다.
- 2D 동차변환은 변환 합성의 뜻까지만 다루고, 3D pose 설명은 다음 경로로 미룬다.
