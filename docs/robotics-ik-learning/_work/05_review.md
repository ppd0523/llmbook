# 1단계 기술 검증

## 1. 검증 대상

- 정의: 기구학, FK, IK, 링크, 관절, 자유도, 구성공간, 관절공간, 작업공간, 자세, 특이점
- 수식: 2D 회전행렬, 2R FK, 코사인 법칙 기반 IK, 도달 조건, 동차변환
- 실습: FK의 팔꿈치·손 좌표, IK 두 분기, 도달 불가, 특이점, FK 검산
- 용어와 표기: 방위와 방향, DoF, 좌표계 첨자, $s_2$ 분기
- 가정과 단위: 양의 링크 길이, 같은 길이 단위, 모든 각도 회전 가능, 관절 제한·충돌 제외

## 5. 수식 검증

| 수식 | 의미·조건 | 상태 |
|---|---|---|
| $R(\theta)$ | 열벡터, 반시계 양의 회전 | 확인 |
| $x,y$ FK 식 | $\theta_2$는 링크 1 기준 상대각 | 확인 |
| $|l_1-l_2|\le r\le l_1+l_2$ | 모든 각도 허용, 관절 제한·충돌 제외 | 확인 |
| $c_2=(r^2-l_1^2-l_2^2)/(2l_1l_2)$ | $-\pi\le\theta_2\le\pi$ 대표값에서의 코사인 법칙, $\gamma=\pi-|\theta_2|$, 코사인의 짝함수 성질 | 확인 |
| $s_2=\pm\sqrt{1-c_2^2}$ | 양의·음의 제곱근 분기, 일반 위치에서는 부호가 반대이고 경계에서는 둘 다 0. 단, 같은 길이 링크의 원점에서는 $\theta_1$이 정해지지 않음 | 확인 |
| $\theta_1=\alpha-\beta$ | 목표선과 링크 합성벡터의 각 차이 | 확인 |
| ${}^A T_C={}^A T_B{}^B T_C$ | 열벡터 좌표 변환, 오른쪽부터 적용 | 확인 |

## 7. 남은 위험

- 실제 로봇의 관절 제한과 충돌을 적용하면 기하학적으로 도달 가능한 해도 사용할 수 없을 수 있다.
- 각도는 $360°$ 주기로 같은 자세를 나타내므로 소프트웨어마다 반환 각 범위가 다를 수 있다.
- 부동소수점 계산에서는 작업공간 경계에서 작은 반올림 오차가 생길 수 있어 실습은 허용오차와 범위 제한을 사용한다.
- 링크 길이가 같고 목표가 원점인 퇴화 사례는 일반적인 두 해가 아니라 무한한 해를 가지므로 별도 처리해야 한다.

## 8. 검증 결론

정의, 수식, 예제와 실습에 미해결 기술 오류가 없다. 코사인 법칙 유도, 계산 순서, 분기 경계, 작업공간의 퇴화 사례와 FK 검산을 보강하여 본문만으로 연습문제를 풀 수 있게 했다.
