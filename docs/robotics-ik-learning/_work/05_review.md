# 기술 검증

## 1. 검증 대상

- 정의: FK·IK·자유도·특이점의 사용 범위
- 수식: 2D 회전행렬, 2R FK, 코사인 법칙 기반 IK, 도달 조건
- 코드: FK/IK HTML 실습의 계산식과 목표점 처리
- 그림: 두 해와 특이점의 시각적 구분
- 출처: Modern Robotics, MIT OCW, IEEE RAS 자료

| 위치 | 항목 | 결과 | 상태 |

## 3. 계산 검증

| 입력 | 계산 결과 | 기대 결과 | 확인 |

| $l_1=3$, $l_2=2$, 목표 $(5,0)$ | $c_2=1$, $\theta_2=0$ | 도달 가능·특이점 | 일치 |

## 6. 결론

- 핵심 수식과 예제 계산은 일치한다.
- 제어·동역학은 범위에서 제외되어 있어 기술 주장에 포함하지 않았다.
- HTML 실습은 브라우저에서 목표점·관절각 변경 시 같은 FK·IK 식을 사용한다. 전체 MkDocs 빌드와 정적 링크 검수는 출판 단계에서 수행한다.
- 목표 $(3,2)$에서 $s_2>0$ 분기의 팔꿈치 $(3,0)$, $s_2<0$ 분기의 팔꿈치 약 $(1.154,2.769)$를 계산해 분기 라벨 수정을 검증했다.
