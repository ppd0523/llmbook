# 퇴고 계획 및 반영 내역

## 1. 퇴고 목표

- 회전행렬을 수식보다 링크 방향의 직관으로 먼저 연결한다.
- FK와 IK를 각각의 입출력으로 대비해 혼동을 줄인다.
- IK 직후에 도달 조건·두 해·특이점을 배치해 잘못된 일반화를 막는다.
- Worked Example 뒤에 대응하는 HTML 실습을 배치한다.
