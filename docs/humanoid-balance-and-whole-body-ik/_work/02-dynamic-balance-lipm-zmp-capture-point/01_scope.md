# 6단계 작성 범위 정의

## 1. 주제

- 다룰 주제: 휴머노이드 동적 균형의 기초와 선형 역진자 모형
- 중심 질문: CoM 위치만 보는 정적 판단을 속도·가속도와 지면반력까지 확장하여, 현재 발 안에서 멈출 수 있는지 또는 새 발 위치가 필요한지를 어떻게 판단하는가?
- 해결할 문제: 5단계 전신 IK의 순간 자세 계산과 후속 locomotion의 동역학·발걸음 계획 사이에 필요한 개념 다리를 만든다.
- 기술 영역: 궤적, 뉴턴 운동법칙, 전신 질량중심 동역학, 지면반력, CoP·ZMP, 선형 역진자 모형, 캡처 포인트, 접촉 전환

## 2. 독자 상태 진단

### 2.1 기준 독자

- 고등학교 수준의 행렬과 삼각함수를 안다.
- 1~5단계를 학습해 회전행렬, 강체변환, 6R FK, 자코비안 수치 IK와 전신 IK를 안다.
- 미분방정식, 동역학, 운동량과 최적제어는 처음일 수 있다.
- 구현보다 손계산, 시각적 실험과 모델의 적용 조건 판별을 우선한다.

### 2.2 선행지식

- 반드시 알고 있어야 하는 개념: 벡터, 행렬 곱, 삼각함수, 위치·속력의 일상적 의미, 5단계의 CoM·지지 다각형·단일/이중 지지
- 알고 있으면 좋은 개념: 함수의 기울기, 뉴턴의 운동법칙
- 모른다고 가정할 개념: 시간 미분, 궤적, 외력 합, 모멘트, 지면반력, CoP, ZMP, LIPM, 캡처 포인트, 하이브리드 시스템
- 처음 등장할 때 설명할 용어: 상태, 일반화 속도, 궤적, 속도, 가속도, 선운동량, 각운동량, 모멘트, 지면반력, 압력중심, 영모멘트점, 축소 모형, 선형 역진자 모형, 고유 주파수, LIPM 시정수, 캡처 포인트, 하이브리드 동역학

### 2.3 실패 가능 지점

- CoM 투영이 지지 다각형 안이면 움직이는 로봇도 항상 안전하다고 오해한다.
- CoP와 ZMP를 조건 없이 완전히 같은 용어로 취급한다.
- LIPM의 점질량·일정 높이·각운동량 변화 무시 가정을 잊는다.
- 역진자 식의 양의 부호를 일반 진자 식과 혼동한다.
- 캡처 포인트를 모든 휴머노이드에 정확한 발 위치로 오해한다.
- 속도와 가속도의 단위 또는 유한차분에서 시간 간격 제곱을 놓친다.
- 한 시점의 IK와 시간에 따른 운동 계획, 저수준 제어를 섞는다.

## 3. 학습 목표

이 장을 마치면 독자는 다음을 할 수 있어야 한다.

1. 자세·상태·궤적을 구분하고 이산 위치 표에서 속도와 가속도를 근사한다.
2. 전신 CoM 가속도와 외력 합의 관계를 뉴턴 법칙으로 적는다.
3. 지면반력, CoP와 ZMP의 물리적 의미와 적용 조건을 설명한다.
4. LIPM의 가정에서 \(\ddot x=\frac gh(x-p)\)를 유도한다.
5. CoM 상태에서 요구 CoP와 캡처 포인트를 계산한다.
6. CoM 투영과 캡처 포인트의 지지 구간 포함 여부를 서로 다른 판단으로 비교한다.
7. 단일·이중 지지와 충돌을 연속 구간·이산 사건으로 구분한다.
8. 축소 모형의 출력이 5단계 전신 IK의 과제 목표로 전달되는 흐름을 설명한다.
9. LIPM의 결과를 사용할 수 없는 상황을 조건에서 판별한다.

## 4. 포함 범위

- 자세, 상태, 궤적과 시간 간격
- 전진·중앙 유한차분의 직관
- 부드러운 5차 시간 스케일의 의미와 식
- \(M\ddot{\mathbf p}_G=M\mathbf g+\sum\mathbf f_i\)
- 2D 모멘트와 지면반력 합력
- CoP와 ZMP의 구분 및 지지 영역 조건
- LIPM 가정과 유도, 고유 주파수 \(\omega=\sqrt{g/h}\), 시정수 \(T_c=\sqrt{h/g}\)
- 요구 CoP \(p_{\mathrm{req}}=x-\frac hg\ddot x_d\)
- 캡처 포인트 \(\xi=x+\dot x/\omega\)
- 단일·이중 지지와 하이브리드 접촉
- Worked Example 3개와 연습문제 12개
- LIPM 동적 균형 인터랙티브 HTML 실습
