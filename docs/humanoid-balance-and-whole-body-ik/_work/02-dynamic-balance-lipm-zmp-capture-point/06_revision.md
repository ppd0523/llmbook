# 6장 퇴고 계획 및 반영 내역

## 1. 퇴고 목표

- 구조 개선: 5장의 정적 전신 IK에서 시간·외력·동적 균형으로 한 단계씩 확장한다.
- 학습성 개선: 미분을 처음 보는 독자도 위치 표의 차분과 단위를 통해 속도·가속도에 진입하게 한다.
- 누락 보강: CoP와 ZMP의 차이, 시정수, CP 적용 조건, 연속 운동과 이산 접촉 전환을 설명한다.
- 중복 제거: LIPM 가정은 유도 전에 모으고, 적용 경계에서는 위반 사례와 필요한 보강만 비교한다.
- 예제 개선: 한 발 안의 요구 CoP와 CP가 지지 구간 밖인 사례를 수치로 대비한다.
- 연습문제 개선: 계산, 개념 비교, 가정 위반, 5장 전신 IK와의 연결을 고르게 포함한다.

## 8. 재퇴고 결론

- 학습 목표를 11개에서 8개로 묶어 장의 중심 질문과 직접 대응시켰다.
- 전신 상태 → 1D LIPM 상태 → 위치·속도 → 외력 → CoP·ZMP → LIPM → CP 순서에서 새 용어가 정의보다 먼저 나오지 않는지 다시 확인했다.
