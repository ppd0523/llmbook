# 5단계 범위 정의

## 핵심 질문

바닥에 닿은 지지발을 움직이지 않게 유지하면서 골반과 스윙발의 목표를 전신 관절벡터에 연결하고, 목표가 충돌할 때 중요한 과제를 보존하는 전신 역기구학을 어떻게 구성하고 검산하는가?

## 독자 상태 진단

### 숙련도와 경험

- 고등학교 수준의 행렬과 삼각함수를 알고 1~4단계를 마친 로보틱스 입문자다.
- 직렬 매니퓰레이터 FK, 회전행렬, 동차변환, 자코비안, DLS, 의사역행렬과 영공간을 학습했다.
- 휴머노이드 모델, 부유 베이스, 접촉 과제, 과제 우선순위와 부등식 제약은 모른다고 가정한다.
- 코드 구현 경험은 요구하지 않는다. 독립 실행형 브라우저 실습에서 알고리즘 결과를 비교한다.
- 논문 수식 전체를 읽는 능력보다 전신 IK 문제를 올바르게 세우고 실패 원인을 구분하는 능력을 우선한다.

### 선행지식으로 가정할 용어

- 관절벡터, FK, TCP, 기준 좌표계, 회전행렬, 동차변환
- 자코비안, 국소 선형 근사, 의사역행렬, DLS, 영공간
- 위치·방위 오차, 가중치, 관절 제한과 특이점

### 처음 등장할 때 설명할 새 용어

- 기구학 트리, 부유 베이스, 일반화 좌표
- 지지발, 스윙발, 단일 지지, 이중 지지, 접촉 과제
- 전신 역기구학, 과제 계층, 엄격한 우선순위
- 등식 제약, 부등식 제약, 투영 자코비안
- 질량중심, 질량중심 자코비안, 지지 다각형
- 기구학적 실행 가능성, 접촉 전환

### 실패 가능 지점

- 부유 베이스의 여섯 자유도를 모터가 직접 움직이는 관절로 오해할 수 있다.
- 지지발 오차에 큰 가중치를 주는 것과 지지발을 엄격히 고정하는 것을 같은 방법으로 오해할 수 있다.
- 영공간 투영의 곱셈 순서와 두 번째 과제의 남은 오차 항을 생략할 수 있다.
- 관절값을 푼 뒤 단순히 잘라 내면 높은 우선순위 접촉도 깨질 수 있음을 놓칠 수 있다.
- 질량중심 투영이 지지 다각형 안에 있다는 사실만으로 동적 보행 안정성이 보장된다고 오해할 수 있다.
- 전신 IK를 PID·PD 제어, 힘 제어 또는 보행 제어기와 혼동할 수 있다.

## 대상 독자와 학습 목적

- 전공/배경: 로보틱스에 관심 있는 고등학생 또는 비전공 입문자
- 학습 목적: 휴머노이드 locomotion을 배우기 전에 전신 기구학 문제의 변수, 과제, 제약과 우선순위를 읽고 구성한다.
- 독자가 원하는 결과: 지지발·스윙발·골반·자세 목표를 하나의 반복 IK로 연결하고, 단일 지지와 이중 지지의 차이를 설명한다.
- 우선순위: 개념 이해 → 손계산 → 실습 비교 → 알고리즘 독해

## 학습 목표

학습자는 이 장을 마친 뒤 다음을 할 수 있어야 한다.

1. 직렬 체인과 휴머노이드 기구학 트리의 차이를 설명하고 부유 베이스가 포함된 일반화 좌표를 구성한다.
2. 지지발, 스윙발, 골반, 질량중심과 자세 과제를 오차벡터·자코비안 쌍으로 적는다.
3. 단일 지지와 이중 지지에서 가장 높은 우선순위의 접촉 과제를 구분한다.
4. 가중 최소제곱과 엄격한 과제 우선순위가 충돌하는 목표를 처리하는 방식을 비교한다.
5. 두 단계 영공간 투영식을 계산하고 낮은 과제가 높은 과제를 1차 근사에서 바꾸지 않음을 검산한다.
6. 관절 제한을 부등식 제약으로 적고 사후 클리핑의 문제를 설명한다.
7. 질량중심과 지지 다각형을 기구학적으로 해석하되 동적 안정성과 구분한다.
8. 반복 전신 IK의 입력, 갱신, 단계별 종료 조건과 실패 보고 항목을 구성한다.
9. 실습에서 가중 해와 우선순위 해의 지지발 오차를 비교하고 목표 충돌의 원인을 진단한다.

## 포함 범위

- 직렬 체인에서 기구학 트리로의 확장
- 세계 좌표계에 대해 움직이는 부유 베이스와 일반화 좌표의 개념
- 전신 프레임 FK와 프레임별 자코비안
- 지지발의 위치·방위 고정 과제와 단일·이중 지지
- 스윙발, 골반, 질량중심과 기준 자세 과제
- 질량중심의 질량 가중 위치와 질량중심 자코비안
- 가중 DLS 누적과 가중치의 한계
- 두 단계 및 여러 단계의 영공간 기반 과제 우선순위
- 등식 제약과 관절 제한·안전 범위 같은 부등식 제약의 구분
- 계층형 최소제곱·계층형 이차계획법의 역할을 개념 수준에서 소개
- 반복 전신 IK, 단계별 잔차, 접촉 전환과 실행 가능성 판정
- 지지 다각형과 질량중심 수직 투영의 정적 기하 해석
- 외부 라이브러리 없는 평면 전신 IK 비교 HTML 실습
- Worked Example 2개와 연습문제 12개

## 제외 범위

- PID·PD 제어, 임피던스 제어와 모든 피드백 제어기 설계
- 힘·토크 명령, 접촉력 분배, 마찰원뿔과 역동역학
- 질량행렬, 코리올리항, 중력 보상과 운동방정식
- ZMP, 캡처 포인트, 센트로이달 모멘텀과 동적 안정성 계산
- 발 궤적의 시간 매개화, 보행 패턴 생성과 경로 계획
- 충돌 거리 자코비안과 환경 충돌 회피 구현
- 계층형 이차계획법 솔버의 수치 선형대수와 코드 구현
- URDF 파싱, 특정 로봇 API와 실시간 하드웨어 통합
- 쿼터니언 기반 부유 베이스 적분의 상세 구현

## 성공 기준

- 독자가 부유 베이스와 관절을 포함한 전신 변수의 역할을 구분한다.
- 독자가 지지발 접촉을 $J_s\Delta\mathbf q=\mathbf0$으로 표현하고 그 우선순위를 설명한다.
- 독자가 두 과제 영공간 투영 Worked Example을 손으로 계산한다.
- 독자가 관절 제한 때문에 골반 목표와 지지발 고정이 충돌하는 예에서 우선순위 해를 고른다.
- 독자가 단일 지지와 이중 지지에서 사용 가능한 여유 자유도가 달라지는 이유를 설명한다.
- 독자가 실습에서 가중 해의 지지발 드리프트와 우선순위 해의 보존 정도를 수치로 비교한다.
- 독자가 기구학적 실행 가능성과 동적 보행 안정성을 구분한다.
