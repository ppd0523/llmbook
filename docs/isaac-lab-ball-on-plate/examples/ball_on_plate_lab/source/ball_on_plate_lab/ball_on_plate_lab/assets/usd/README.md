# Generated USD location

Run the conversion in chapter 3. Isaac Sim 6's URDF importer chooses the file name from the robot name. With this URDF, the expected root layer is:

```text
ball_on_plate/ball_on_plate.usd
```

The generated layers are intentionally not checked into this documentation repository because the documentation-building laptop cannot run Isaac Sim. Keep the entire generated directory together; the root USD may reference sibling layers.
